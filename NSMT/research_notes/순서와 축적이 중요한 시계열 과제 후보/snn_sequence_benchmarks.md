# Sequence benchmarks used in the SNN literature for input order and long accumulation (as of November 2026)

Reading conventions for these notes

- Every number below was read in the cited paper's table or text (arXiv PDF/HTML or the Nature HTML page, fetched 2026-11-25). The table or section is given next to it. "(reported by X)" means the number was read in X's comparison table, not in the original paper.
- "FF" = feedforward SNN, "Rec" = recurrent SNN. "Params" = trainable parameters.
- "STP" = Segregated Temporal Probe, a three-way training comparison introduced by the PolyU group: STBP (normal training through time), SDBP (the neuron state still carries forward in time, but no gradient flows backward in time), NoTD (the neuron state is cut at every step, so each time step is processed alone, i.e. a memory-less network). NoTD is a memory-removal control, not an order-shuffle control.
- Venue status is given per paper; "arXiv only" means I found no peer-reviewed version.
- The earlier internal report already covers delayed-cue ECG, PPG-DaLiA, EigenWorms, sleep staging, raw Speech Commands data size, and the Long Range Arena locality critique. These notes repeat those only where a new SNN number or a new control exists.

## Key question 1: Which benchmarks do peer-reviewed SNN papers use for long temporal dependencies?

### Takeaway
The standard set in neuron-model papers is sequential MNIST / permuted sequential MNIST (784 steps), SHD / SSC (250 bins), Google Speech Commands, and (since 2024) pixel-level sequential CIFAR-10 (1024 steps) and Long Range Arena; ECG wave labelling on QTDB, delayed spiking XOR, store-recall and binary adding are the smaller recurring ones. New since the internal report: two benchmark papers from one group (IJCAI 2025 "Neuromorphic Sequential Arena", IEEE TNNLS 2026 survey) show with a memory-removal probe that most classic SNN benchmarks need little temporal processing, and PMSN (IEEE TNNLS 2026) is the first peer-reviewed SNN paper I found that reports the UEA long-series set (EigenWorms etc.) and PPG-DaLiA.

### Inferences
- The neuron-model papers (LSNN, SRNN, TC-LIF, DH-SNN, PMSN, D-RF, DMP) share one template: S/PS-MNIST + SHD (+ SSC, GSC), with 0.04–0.2 M parameters. The state-space papers (Binary S4D, SpikingSSM, P-SpikeSSM, LongSpike, D-RF) share another: LRA + sCIFAR + raw Speech Commands. A paper that uses neither template will be asked why.
- Genuine physical time series appear in peer-reviewed SNN temporal-processing papers only in a few places: QTDB ECG (Yin 2021, BRF, SE-adLIF, Rhythm-SNN), DEAP EEG (DH-SNN), WISDM / OpenBMI / SLoClas / N-DNS (NSA), UEA-6 and PPG-DaLiA (PMSN), primate reaching and Mackey-Glass (NeuroBench), and the forecasting sets (TS-LIF, CPG-PE).
- f-SNN (ICLR 2026) does not provide any long-sequence evidence for fractional-order neurons; the only such evidence is the arXiv-only follow-up LongSpike, which is a state-space model, not a plain f-LIF network.

### Gaps
- N-TIDIGITS: none of the papers I read reports it in a main table; I found no 2023–2026 numbers and cannot give a current state of the art.
- Copy task and the classic real-valued adding problem: not found in the SNN papers read; the SNN literature uses delayed spiking XOR, STORE-RECALL and the survey's Binary Adding instead.
- DH-SNN Table 1 and its Supplementary Table S6 (DEAP numbers) are images/linked tables on the Nature page and were not readable; DH-LIF numbers below come from other papers' comparison tables.
- LSNN TIMIT numbers and the store-recall error values in Rhythm-SNN (Fig. 3c) were not extracted.

## Key question 2: Per benchmark — length, input form, metric, best SNN numbers, non-spiking baselines, and the gap

### Takeaway
On every classic benchmark a sub-0.5 M-parameter SNN is within about 1–3 %p of the best non-spiking number (psMNIST 98.2–98.5 vs 98.7; raw Speech Commands-35 96.1–96.3 vs 96.25; LRA average 84.3 peer-reviewed vs 85.5), with pixel-level sequential CIFAR-10 the main exception at small size (82–84 % at 0.21 M vs 91.13 % for S4). On the physical-signal sets with SNN numbers (QTDB ECG, UEA-6, PPG-DaLiA) the published SNN numbers are at or above the non-spiking baselines, but each rests on one or two papers.

## Key question 3: What published evidence exists that ORDER matters and that LONG accumulation matters?

### Takeaway
Published controls almost all test memory (remove the neuron state, vary the delay, vary the sequence length), not order; I found true order controls only for SHD / SSC (time reversal: networks without learned delays "perform well under time reversal") and for the purpose-built DVS-Gesture-Chain and burst-sequence tasks. Permuted sMNIST is a fixed permutation and is not a shuffle control; the memory-removal probe shows that MNIST-as-static, DVS-type sets and DVS-Gesture need no memory at all, GSC / SHD / SSC need only short-term forward integration, and PTB, PS-MNIST, Binary Adding and the seven NSA tasks do need memory.

### Cited Findings

- SHD / SSC without timing: classifiers "trained on spike count patterns without temporal information were unable to surpass the 60 % accuracy mark for the SHD and the 30 % mark for the SSC dataset"; LSTM with temporal histograms 85.7 % / 75.0 % (Cramer et al., Section "Results", Fig. 3) — [Cramer 2020](https://arxiv.org/abs/1910.07407)
- SHD / SSC time reversal (Yu, Sun, Akarca, Goodman; Neuromorphic Computing and Engineering 2026, DOI 10.1088/2634-4386/ae46d5 per OpenAlex; arXiv v3 read): "when axonal delays are not used, networks perform well under time reversal, whereas networks trained with delays perform poorly" (abstract); an MLP on per-sample spike counts reaches "around 50% for SHD"; on count-normalized variants (rate information removed) a plain SNN reaches 23 % on SHD-norm and 15 % on SSC-norm, with learned delays 48 % and 33 % (Section on timing-normalized datasets) — [Yu et al.](https://arxiv.org/abs/2507.16043)
- DVS Gesture vs DVS-Gesture-Chain: plain DVS Gesture "can be solved by networks without temporal feature extraction when its events are accumulated in frames", the chained version "demands an understanding of the order in which events happen" (abstract) — [DVS-GC](https://arxiv.org/abs/2209.14915)
- Burst sequence detection (synthetic; a class is "a specific pre-defined temporal sequence of bursts across a fixed sub-population of three" input neurons, with distractor bursts and 50 Hz background): adaptive-LIF networks "clearly outperformed LIF networks" at equal parameter count (Fig. 7a, b) — [SE-adLIF](https://arxiv.org/abs/2408.07517)
- Permuted sMNIST is a fixed permutation: "The pixel order is then shuffled using a fixed random permutation matrix, disrupting locality" (TNNLS survey, Section IV-A); SpikingSSM describes it as "a fixed permutation to the pixels, thereby distorting the temporal structure" — [Ma et al.](https://arxiv.org/abs/2502.09449); [SpikingSSM](https://arxiv.org/abs/2408.14909)
- Attention with position information solves PS-MNIST at small size: non-spiking Transformer 97.64 and Spike-Driven Transformer 96.21 at about 90K parameters (TNNLS survey Table VI) — [Ma et al.](https://arxiv.org/abs/2502.09449)
- Long Range Arena is mostly local and position-driven (arXiv only): a convolutional model limited to 30 tokens per layer gets "fairly close to state-of-the-art performance in each task"; "the extreme cases are the textual tasks, where a distance bound of 2 tokens per layer is sufficient" (Text 88.96 %, Retrieval 90.32 % at kernel 5); Pathfinder stays at 51–52 % until kernel 61 (72.28 %) (Table 1, Section 8) — [Miralles-González et al.](https://arxiv.org/abs/2501.14850)
- Positional encoding on LRA (same paper, Table 4; Transformer with their training recipe): summed learned position embeddings / summed sinusoidal / rotary = Image 67.87 / 85.52 / 88.15; Pathfinder 90.48 / 92.81 / 96.28; Text 64.49 / 88.47 / 90.33; Retrieval 83.31 / 87.06 / 90.80; ListOps 41.30 / 47.55 / 62.90; average 69.49 / 80.28 / 85.69 — [Miralles-González et al.](https://arxiv.org/abs/2501.14850)
- ListOps is partly order-free by construction: "As each mathematical operation in the task is commutative, we can shuffle the order of the operands without" changing the label (used as an augmentation; Section 6) — [Miralles-González et al.](https://arxiv.org/abs/2501.14850)
- Forecasting barely depends on position information: Spikformer without positional encoding averages R² .719 vs .733 with relative positional encoding, and order-aware SpikeRNN without positional encoding .768 (CPG-PE Table 1) — [CPG-PE](https://arxiv.org/abs/2405.14362)

### Inferences
- NoTD is a memory-removal control. A task can fail under NoTD and still be order-insensitive (e.g. counting or summing). Binary Adding and delayed XOR are of this kind: the label is a sum or XOR of marked values, which does not change if the marked items swap places, so they prove accumulation over a long span but not order sensitivity.
- Permuted sMNIST does not test order sensitivity in the shuffle-control sense: the permutation is the same for every sample, so any model that knows the position of each input (positional encoding, or a readout indexed by position) sees an ordinary MNIST problem; the 96–98 % of small Transformers with position information is consistent with this. What PS-MNIST tests is whether a step-by-step state can carry information over hundreds of steps (feedforward LIF = chance).
- The only published order control on a standard SNN benchmark (SHD / SSC time reversal) goes against the benchmark: ordinary SNNs without learned delays are largely insensitive to reversing time, i.e. they use counts and intervals rather than order.
- Among the tasks seen, order is necessary by construction in: NSA's AL (turns change the heading, so the same actions in a different order end at a different place — my reading of the task description), DVS-Gesture-Chain, burst sequence detection, SHD-Adding only weakly (the sum is commutative; it needs memory, not order), and QTDB wave labelling in a local sense (the wave identity depends on what came just before).
- I found no published per-sample shuffle control (shuffling time steps or tokens at test time) on S/PS-MNIST, sCIFAR, Speech Commands, QTDB, UEA-6, PPG-DaLiA or any NSA task. Any claim that these "reward order" would have to be established by the lab's own shuffle control.
- NSA's Table 4 is the closest published analogue to the lab's comparison: with one spiking step per input step (D = 1) and about 0.1 M parameters, the attention-based Spike-Driven Transformer is the weakest architecture on HAR (71.07 vs 89.37), SSL (5.75 vs 82.39) and ASR, while state-carrying models lead. This is evidence that on these tasks a state path matters more than attention, though the paper gives no positional-encoding ablation.

### Gaps
- No bag-of-features baseline or "attention without positional encoding" ablation was found for WISDM-HAR, OpenBMI, SLoClas, QTDB, UEA-6 or PPG-DaLiA in SNN papers.
- The STP values for PTB / PS-MNIST / Binary Adding are only plotted (Fig. 6), not tabulated.
- DVS-GC accuracy tables (Tables 3–5) were not extracted; only the abstract-level claim is cited.
- The time-reversal accuracies for SHD / SSC are in figures; only the count-normalized numbers at zero perturbation were read in the text.
- "Never Train from Scratch" (Amos et al., ICLR 2024) was downloaded but not read in detail; it is cited only through the locality paper's summary.

## Key question 4: Which of these are genuine time series that a time-series reviewer would accept?

### Takeaway

- UEA long series and PPG-DaLiA are described by PMSN as "real-world temporal processing scenarios, ranging from scientific time-series analysis to practical applications in healthcare", evaluated with "the same preprocessing and evaluation protocols" as Log-NCDE and LinOSS (Section VII-A) — [PMSN](https://arxiv.org/abs/2408.14917)
- WISDM HAR: "gyroscope data collected from a smartwatch. The data is recorded at 20 Hz and segmented into 10-second intervals"; OpenBMI EEG motor imagery; SLoClas sound source localization; N-DNS audio denoising; AISHELL speech recognition (NSA Section 2.2, Table 1) — [NSA](https://arxiv.org/abs/2505.22035)
- NSA's HAR preprocessing: windows of 200 steps "with a hop length of 100 time steps. The data from all subjects is z-score normalized per coordinate, shuffled, and split into training and testing sets" (Supplementary "Data Preprocessing") — [NSA](https://arxiv.org/abs/2505.22035)
- Raw speech is called "a typical real-world time series domain, involving signals sampled from an underlying physical process at high frequency" by the S4 authors (Section 4.2) — [S4](https://arxiv.org/abs/2111.00396)
- DEAP: "32-channel EEG data and 8-channel peripheral physiological signals" from 32 participants, three-level valence / arousal classification (DH-SNN Results and Methods) — [DH-SNN](https://www.nature.com/articles/s41467-023-44614-z)
- Primate reaching: "multi-channel recordings from the sensorimotor cortex of two non-human primates" with finger velocity as target (NeuroBench task description) — [NeuroBench](https://arxiv.org/abs/2304.04640)
- Flattened images: S/PS-MNIST "built by performing a raster scan on the original MNIST" (Rhythm-SNN Methods); sCIFAR10 is "the IMAGE subset in LRA" (SpikingSSM) — [Rhythm-SNN](https://www.nature.com/articles/s41467-025-63771-x); [SpikingSSM](https://arxiv.org/abs/2408.14909)
- LRA spans "visual data, mathematics expressions, and text" (SpikingSSM, LRA paragraph) — [SpikingSSM](https://arxiv.org/abs/2408.14909)
- SHD / SSC are audio "transformed into spike-based representations using a bionic inner ear model" (Rhythm-SNN Methods) — [Rhythm-SNN](https://www.nature.com/articles/s41467-025-63771-x)

### Inferences
- Acceptable to a time-series reviewer as main results (physical signal, standard protocol shared with non-spiking papers): UEA-6 and PPG-DaLiA (protocol of Log-NCDE / LinOSS), raw Speech Commands (protocol of S4), and the forecasting sets. Acceptable with caveats: QTDB ECG (SNN-specific spike encoding, only an LSTM baseline), WISDM-HAR / OpenBMI / SLoClas in the NSA configuration (SNN-only benchmark; the HAR split shuffles overlapping windows from all subjects before the train/test split, which a time-series reviewer is likely to flag as leakage — my reading of the quoted preprocessing), DEAP (heavily criticised label quality in general; not checked here), primate reaching (neural spikes, regression).
- Not acceptable as time-series evidence, usable only as calibration or sanity checks: S/PS-MNIST, sCIFAR, LRA, PTB, Binary Adding, delayed XOR, STORE-RECALL, AL.
- SHD / SSC / N-TIDIGITS / DVS sets sit in between: physical origin, but event-coded and tied to the neuromorphic community; they were already ruled out by the lab for a different reason (next question).

### Gaps
- Whether the NSA EEG-MI split is subject-independent was not established (only the HAR and one other preprocessing sentence were read).
- No time-series-venue paper (as opposed to SNN-venue paper) was checked for how it treats QTDB wave labelling or NSA tasks.

## Key question 5: Does the lab's SHD objection ("spiking step = time bin is already standard") apply to the other event-based sets — and beyond?

### Takeaway
Yes for every event-based set (SSC, N-TIDIGITS, DVS-Gesture, DVS-Lip, N-MNIST, CIFAR10-DVS), and in practice for almost every benchmark in this inventory: in the recurrent / neuron-model SNN literature one input step (pixel, sample, frame or bin) per spiking step is the default, so aligning T with the sequence axis is not new there. The setting where it is not the default is Transformer-type and TCN-type SNNs, which normally repeat each input for several spiking steps.

### Cited Findings
- Event sets are binned so that the bin is the spiking step: SHD and SSC are run at T = 250, N-MNIST at T = 300, DvsGesture at T = 20, CIFAR10-DVS at T = 10 in the survey's standard configurations (Table I, "Time Step (T)" column) — [Ma et al.](https://arxiv.org/abs/2502.09449)
- Same practice for non-event inputs: S/PS-MNIST pixels "are fed to an SNN one pixel at a time" (survey Section IV-A); GSC is run at T = 101 Mel frames (Table I); ECG is given one level-crossing sample per step with a label per step (Yin 2021, Methods and Fig. 3a); NSA lists "Sequence length" 200–500 as the number of simulation steps (Table 1) — [Ma et al.](https://arxiv.org/abs/2502.09449); [Yin 2021](https://arxiv.org/abs/2103.12593); [NSA](https://arxiv.org/abs/2505.22035)
- Transformer / TCN SNNs are the exception: "Spiking TCN and Spike-Driven Transformer ... are originally designed to repeat each time step D times to enhance their model representation power" (NSA Section 3.2); the survey's Table VI reports Spike-Driven Transformer with internal window 4 and 1 (PS-MNIST 96.21 vs 95.01; PTB perplexity 152.41 vs 327.82; Binary Adding 98.15 vs 88.05) — [NSA](https://arxiv.org/abs/2505.22035); [Ma et al.](https://arxiv.org/abs/2502.09449)
- DVS-type sets additionally fail the memory test: NoTD matches or beats full training on N-MNIST, CIFAR10-DVS, DVS-Gesture, DVS-SLR, GAIT-DAY-DVS, HARDVS (NSA Table S3) — [NSA](https://arxiv.org/abs/2505.22035)
- Event-by-event processing without binning exists as a non-spiking alternative (Event-SSM marks its rows "Async. events ✓" against binned SNN rows "✗"; Tables 2, 3) — [Event-SSM](https://arxiv.org/abs/2404.18508)

### Inferences
- The objection the lab raised for SHD applies unchanged to SSC, N-TIDIGITS and all DVS sets (native events, bin = step). DVS sets have the further problem that published probes show they need no memory.
- The objection also applies, in weaker form, to S/PS-MNIST, QTDB, GSC (frames) and the NSA tasks when the comparison class is recurrent SNNs: there "one sample per spiking step" is the convention, not a contribution. A T = N contribution is therefore only distinctive relative to Spikformer-type models, which is exactly the comparison in NSA Table 4 and the survey's Table VI (internal window 1 vs 4): with window 1 the spiking Transformer loses accuracy on PS-MNIST, PTB and Binary Adding.
- Consequently, on any of these benchmarks the lab's novelty statement would need to be "a Transformer-type SNN whose sequential path runs at one token per spiking step", and the natural published baselines are the state-carrying models (PMSN, Binary S4D / GSU, SpikingSSM), not only Spikformer.

### Gaps
- No N-TIDIGITS processing details were read; the statement for it rests on its being a native event-audio set like SHD.
- I did not find a paper that explicitly discusses "T = token axis" as a design choice for spiking Transformers beyond the NSA / survey remarks on the repeat factor D.

## Key question 6: Compute cost and whether small models (< 1.5 M parameters) reach the published level

### Takeaway
Small models are the norm: published state-of-the-art SNN numbers use 0.04–0.2 M parameters on S/PS-MNIST and SHD, about 0.2–0.3 M on pixel sCIFAR and raw Speech Commands, about 0.1 M on four NSA tasks, 2–5 k on QTDB, and 0.004–1 M on UEA-6; the cost problem is sequence length, not model size (raw Speech Commands about 26 min per epoch for a 305K spiking state-space model; step-by-step SNNs slow down sharply beyond a few hundred steps).

### Cited Findings
- Parameter counts at the published level: S/PS-MNIST 66.3k–156.4k (PMSN), 155.1k (D-RF), 61K–202K (DMP); SHD 37.5k–0.45 M (SE-adLIF), 199.3k (PMSN), 46K (DMP); pixel sCIFAR 0.21 M (PMSN, D-RF); raw Speech Commands 305K (SpikingSSM, LongSpike); Speech Commands spectrogram 1.69 M (Spiking LMUFormer); LRA Text 0.175 M (Spiking LMUFormer); QTDB 1,734–4.6k (BRF, SE-adLIF) — [PMSN](https://arxiv.org/abs/2408.14917); [D-RF](https://arxiv.org/abs/2509.17186); [DMP](https://arxiv.org/abs/2512.07602); [SE-adLIF](https://arxiv.org/abs/2408.07517); [LongSpike](https://arxiv.org/abs/2606.12895); [LMUFormer](https://arxiv.org/abs/2402.04882); [BRF](https://arxiv.org/abs/2402.14603)
- NSA: "For AL, HAR, EEG-MI, and SSL tasks, the number of trainable parameters is set to approximately 0.1M for all models. For ALR, AD, and ASR tasks, the trainable parameters are approximately 9.5M, 0.4M, and 4.7M"; 100 epochs, batch 256 for the first four tasks (Table S5); hardware "NVIDIA GeForce RTX 3090 GPUs (24GB)" (Supplementary) — [NSA](https://arxiv.org/abs/2505.22035)
- UEA-6 model sizes of the non-spiking baselines (PHCSSM Table 3, copied from Rusch & Rus 2025): e.g. on EigenWorms Log-NCDE 37,977; S5 22,007; Mamba 27,381; LinOSS-IM 134,279; on SCP1 LinOSS-IM 991,240; PHCSSM itself 1,312–4,891 parameters per dataset — [PHCSSM](https://arxiv.org/abs/2604.01295)
- Raw Speech Commands training time: SpikingSSM about 26.5 min per epoch and 14,429 MiB; LongSpike about 27.5 min and 12,927 MiB, on a single GPU of unspecified type among V100 / A100 / A800 / H800 / RTX cards (LongSpike Table 5 and appendix); SpikingSSM trains Speech Commands for 40 epochs with 6 layers of width 128 (SpikingSSM Table 12) — [LongSpike](https://arxiv.org/abs/2606.12895); [SpikingSSM](https://arxiv.org/abs/2408.14909)
- SpikingSSM settings for other tasks (Table 12): psMNIST 4 layers × 256, 100 epochs; sMNIST 2 × 400, 100 epochs; LRA Image 6 × 512, 200 epochs; Pathfinder 6 × 256, 200 epochs; ListOps 8 × 128, 40 epochs; its training-speed table gives 1480 ms for iterative LIF vs 230 ms with its parallel surrogate on sCIFAR10 (Table 5 "Speed (ms)") — [SpikingSSM](https://arxiv.org/abs/2408.14909)
- P-SpikeSSM: 200 epochs on every task; "Nvidia RTX A5000 GPUs (8) each with 24GB"; memory "≈ 23GB for SC10" (Section 4, Table S1, Appendix C) — [P-SpikeSSM](https://arxiv.org/abs/2406.02923)
- Step-by-step vs parallel neurons: PMSN reports "training speed-up ratios up to 134× and 71× compared to the serial MSN and LIF models" (Section VII-D); NSA finds serial models keep a constant time per step so cost grows linearly with length, and memory "of all evaluated models scales linearly with sequence length" (Section 3.3, Table 5) — [PMSN](https://arxiv.org/abs/2408.14917); [NSA](https://arxiv.org/abs/2505.22035)
- LRA Text cost for 0.175 M models: Spiking LMUFormer 928 s training per epoch-unit in the paper's table vs 738 s for LMUFormer and 1780 s for the Transformer, peak memory 5.66 / 2.46 / 2.49 (LMUFormer Table 8; units as printed there) — [LMUFormer](https://arxiv.org/abs/2402.04882)
- Event-SSM trains on SSC (600 M events per epoch) and DVS (390 M events per epoch) "in 2 – 10 h on a single" GPU (Section 4) — [Event-SSM](https://arxiv.org/abs/2404.18508)

### Inferences
- With 0.2–1.5 M parameters and 4 × 48 GB GPUs, model size is not a barrier on any benchmark listed except ALR / ASR in NSA (9.5 M / 4.7 M) and the large LRA / WikiText settings.
- The realistic risk is the score, not the budget: on S/PS-MNIST, SHD and raw Speech Commands the published numbers are near ceiling (99.5 / 98.2 / 96.2 / 96.3), so a Transformer-type SNN at 95–97 % would look "close" but could not show a clear benefit of the sequential path; on pixel sCIFAR (45 % for LIF vs 82–84 % for dendritic / resonating neurons vs 91 % for S4) and on NSA's HAR / SSL / AL (LIF or spiking Transformer far below state-carrying models) there is room to show a difference, but the comparison rows are strong state-space SNNs.
- Tasks where a T = N path costs little to try (sequence ≤ 500 steps, about 0.1 M parameters, 100 epochs on one 24 GB card in the source paper): NSA's AL, WISDM-HAR, OpenBMI EEG-MI, SLoClas; QTDB (about 1,300 steps per sequence, inferred from BRF Table 1: 35,011.2 spike operations ÷ 26.93 per step; a few thousand parameters). Tasks where step-by-step simulation is expensive: raw Speech Commands (16,000), EigenWorms (17,984), PPG-DaLiA (49,920), LRA (1K–16K) — these need either patching (which shortens T = N to the token count) or a parallel neuron formulation.
- For the three physical-signal sets with the strongest non-spiking comparison protocol (UEA-6, PPG-DaLiA, raw Speech Commands), the published SNN level is reachable only with models that carry state across thousands of steps; with patch tokens the lab's T would be tens to hundreds, which changes the task from "long accumulation in neuron state" to "accumulation across tokens".

### Gaps
- No wall-clock numbers were found for S/PS-MNIST, QTDB, UEA-6 or PPG-DaLiA SNN training (PMSN gives only speed-up ratios; PHCSSM Table 4 run times were not extracted).
- GPU type for the LongSpike / SpikingSSM Speech Commands timing is not stated per experiment.
- Whether PMSN's UEA-6 and PPG-DaLiA model sizes are below 1.5 M was not found in the main text (the tables give no parameter column); the non-spiking baselines' sizes (5 k–1 M) suggest so but this is unverified.
