# 순서와 축적을 함께 입증한 benchmark는 없다

발표된 근거만으로 세 조건을 모두 만족하는 실제 시계열 benchmark는 찾지 못했다. 세 조건은 (가) 순서와 긴 과거의 축적이 필요하다는 입증, (나) 신뢰할 DNN·SNN baseline, (다) 0.2–1.5 M parameter model이 닿을 수 있는 수준이다. classification 노트와 forecasting 노트는 이 결론을 직접 적었고, 나머지 두 노트도 같은 빈자리를 보고했다. 가장 큰 구멍은 (가)다. "표본마다 token 순서를 무작위로 섞은 data로 처음부터 다시 학습하면 점수가 떨어진다"를 실제 시계열 dataset에서 보인 심사 통과 논문이 하나도 없다. 가장 가까운 것은 모든 표본에 같은 순서 바꿈을 적용한 UCR(시계열 classification dataset 모음) 연구와, 철회된 ICLR 2026 투고 한 편이다 ([Zhang 외 2025](https://arxiv.org/abs/2503.20264); [OpenReview 8vgP9VhECt](https://openreview.net/forum?id=8vgP9VhECt)). 발표된 것은 대부분 "과거를 더 보면 점수가 오른다"(축적)까지다. 나쁜 소식이 하나 더 있다. recurrent SNN 문헌에서는 입력 한 step을 spiking step 하나에 넣는 것이 이미 기본이다. 그래서 T = N은 Spikformer식 model과 견줄 때만 새롭다 ([NSA, IJCAI 2025](https://arxiv.org/abs/2505.22035); [Ma 외, IEEE TNNLS 2026](https://arxiv.org/abs/2502.09449)). CinC 2017의 격차는 기억하신 것보다 작지만 없어지지는 않는다. 80 %대(0.825–0.831)는 ensemble(여러 model의 출력을 합친 것)과 수작업 feature가 hidden test set(주최 측만 가진 비공개 test data)에서 받은 점수다 ([Clifford 외, CinC 2017, Table 4](https://www.physionet.org/files/challenge-2017/1.0.0/papers/065-469.pdf)). 단일 deep network를 5-fold로 평가한 값은 74.6–79.2다 ([Zihlmann 외, CinC 2017, Table 1–2](https://arxiv.org/abs/1710.06122)). 실험 기록을 보면 연구실의 66–68 %는 네 class macro-F1이 아니라 바로 그 공식 점수다. 같은 조건의 격차는 약 7–12점이다(추론: 뺄셈) ([MODI 기록 11-01](../../docs/MODI_PROJECT_LOG.md)). 권고는 dataset 하나가 아니라 묶음이다. 어떤 후보든 "섞어서 재학습" 확인을 model 비교보다 먼저 돌린다. 돌릴 순서는 Google Speech Commands(1초짜리 음성 단어), Sleep-EDF 수면 단계, WISDM·OpenBMI(손목 자이로 활동 인식과 EEG 운동 상상), forecasting 쪽 Electricity다(추론). CinC는 공식 점수로 다시 보고해 보조 근거로만 둔다. 여기에 "두 단서의 순서를 바꾸면 답이 바뀌는" 구성 과제를 실제 신호 조각 위에 하나 더한다. EigenWorms 같은 UEA(다변량 시계열 classification dataset 모음)의 긴 dataset, 12-lead ECG rhythm, anomaly detection benchmark, psMNIST(image를 pixel 한 줄로 편 과제)류는 순서 주장에 쓰지 않기를 권한다.

## 읽는 법과 용어

문장은 세 종류로 나눈다. link가 붙은 문장은 논문이나 실험 기록에서 **확인**한 사실이다. "추론"이라고 적은 문장은 조사 노트가 inference로 표시한 것이거나, 이 보고서가 한 계산과 판단이다. "arXiv만"은 심사를 통과한 판을 찾지 못했다는 뜻이다. "초록만"은 본문을 열지 못했다는 뜻이다. "찾지 못했다"는 검색에 나오지 않았다는 뜻이지, 없다는 증명이 아니다. reviewer 의견은 OpenReview의 공개 review를 자동 요약한 것이다. 원문 그대로가 아니므로, 논문에 인용하기 전에 forum에서 다시 확인해야 한다. 연구실 수치는 실험 기록(`docs/MODI_PROJECT_LOG.md`)에서 옮겼다. 절의 순서는 질문 (1) CinC, (3) 표준 benchmark, (2) 후보, (4) 입증 방법, (5) 순위, (6) 확인하지 못한 것이다.

| 용어 | 뜻 |
|---|---|
| T = N | patch token 하나를 spiking step 하나에 넣는다. neuron의 막전위가 token 사이로 과거를 나른다. 이 보고서에서 "state"는 이렇게 막전위에 남은 과거 정보를 말한다. |
| 순서 / 축적 | 순서 = token의 배열이 바뀌면 답이 바뀐다. 축적 = 과거 token을 많이 볼수록 답이 좋아진다. 축적은 배열과 무관할 수 있다. |
| 표본별 shuffle | 표본마다 새 무작위 순서로 token을 섞는다. 순서 정보가 사라진다. |
| 고정 순열 | 모든 표본에 같은 순서 바꿈을 적용한다(psMNIST 방식). 자리마다 늘 같은 정보가 오므로 model이 배울 수 있다. 순서 확인 시험이 아니다. |
| test 때만 shuffle | 원본으로 학습한 model에 섞은 입력을 준다. "이 model이 순서를 쓰는가"를 본다. |
| 섞어서 재학습 | 섞은 data로 처음부터 학습하고 섞은 data로 test 한다. "이 과제가 순서에 보상하는가"를 본다. |
| memory-less control | 같은 model에서 step 사이로 state를 넘기지 않게 한 대조. 축적을 본다. 순서는 가르지 못한다. |
| NoTD | Ma 외와 NSA(Neuromorphic Sequential Arena, SNN용 sequence benchmark 묶음) 논문이 쓰는 memory-less control의 이름. 정상 학습(STBP), 시간 방향 gradient만 끊음(SDBP), state 자체를 매 step 끊음(NoTD)을 비교한다. |
| 순서를 못 보는 baseline | 같은 token을 받지만 배열을 알 수 없는 model. 예: positional encoding 없는 attention에 평균 pooling을 붙인 것. |
| 5-fold cross-validation | 공개 data를 다섯 조각으로 나눠 돌아가며 test 한다. |
| macro-F1 (MF1) | class별 F1의 단순 평균. |
| smoothing 대조 | 조각별 출력을 이웃끼리 고르게 만드는 후처리. 예: HMM(은닉 Markov model). "label이 잘 안 바뀐다"는 가정만 쓰고 새 정보는 더하지 않는다. |
| look-back / horizon | forecasting에서 입력으로 주는 과거 길이 / 맞혀야 하는 미래 길이. |
| PS-MNIST, sequential CIFAR | image를 pixel(또는 열) 하나씩 차례로 넣는 과제. PS-MNIST는 여기에 고정 순열을 건다. 시계열은 아니다. |

## CinC 2017: 80 %대는 ensemble의 hidden test 점수이고, 같은 조건의 격차는 7–12점이다

먼저 바로잡을 것이 있다. 요청문에는 연구실 점수가 "네 class macro-F1 약 66 %"로 적혀 있다. 실험 기록은 다르게 말한다. 연구실의 66–68 %는 대회 공식 점수다. 공식 점수는 Normal, AF(심방세동), Other 세 class F1의 평균이고 Noisy class는 뺀다 ([Clifford 외, Eq. 1](https://www.physionet.org/files/challenge-2017/1.0.0/papers/065-469.pdf)). 5-fold 평균으로 Spikformer식은 **65.74**, Neocortex를 attention의 query로 쓰는 population LIF model은 **67.73**, population f-LIF는 **67.58**이다. Noisy까지 넣은 네 class macro-F1은 각각 **61.39, 62.36, 62.27**이다 ([MODI 기록 11-01](../../docs/MODI_PROJECT_LOG.md)). classification 노트는 66 %를 네 class macro-F1로 놓고 격차를 4–10점으로 어림했다. 그 전제가 기록과 맞지 않아서, 이 보고서는 기록의 값으로 다시 계산했다.

기억하신 "80 %대"는 틀리지 않았다. 다만 조건이 셋 붙는다. 공식 점수이고, hidden test set이고, 대부분 ensemble이나 수작업 feature다. 아래 표가 설정별 수준이다.

| 설정 | 점수 | 무엇인가 | 출처 |
|---|---|---|---|
| 공식 점수, hidden test, 공동 우승 4팀 | 0.825–0.831 | 단계별 이진 classifier, 전문가 feature + deep network ensemble, random forest 등 | [Clifford 외, Table 4](https://www.physionet.org/files/challenge-2017/1.0.0/papers/065-469.pdf); [대회 결과 page](https://moody-challenge.physionet.org/2017/results) |
| 같은 팀들의 training data 점수 | 0.875–0.970 | 주최 측: 우승팀에서도 과적합이 뚜렷했다 | [Clifford 외, Table 4](https://www.physionet.org/files/challenge-2017/1.0.0/papers/065-469.pdf) |
| 여러 팀의 출력을 투표로 합침 | 0.844–0.868 | 단일 model이 낸 점수가 아니다 | [Clifford 외, Table 4](https://www.physionet.org/files/challenge-2017/1.0.0/papers/065-469.pdf) |
| 단일 deep network, 공개 data 5-fold, augmentation 있음 | 79.0 / 79.2 | 24-layer CNN / 같은 CNN + 3-layer LSTM | [Zihlmann 외, Table 1](https://arxiv.org/abs/1710.06122) |
| 같은 model, augmentation 없음 | 75.8 / 74.6 | 위와 같음 | [Zihlmann 외, Table 2](https://arxiv.org/abs/1710.06122) |
| 위 CNN + LSTM 5개의 ensemble, hidden test | 0.82 | | [Zihlmann 외](https://arxiv.org/abs/1710.06122) |
| 연구실, 5-fold, 공식 점수 | 65.74 / 67.73 / 67.58 | Spikformer식(30 epoch) / query population LIF / population f-LIF | [MODI 기록 11-01](../../docs/MODI_PROJECT_LOG.md) |
| 연구실, 5-fold, 네 class macro-F1 | 61.39 / 62.36 / 62.27 | 같은 순서 | [MODI 기록 11-01](../../docs/MODI_PROJECT_LOG.md) |

"80 %대"가 실제보다 높게 기억되는 이유는 셋이다(추론). 첫째, 공식 점수는 가장 어려운 class를 뺀다. Zihlmann의 단일 model은 Noisy F1이 54.9–65.3이다 ([Zihlmann 외, Table 1–2](https://arxiv.org/abs/1710.06122)). 둘째, hidden test 점수는 ensemble과 feature 묶음의 것이다. 같은 팀의 단일 model을 5-fold로 재면 3–7점 낮다. 셋째, hidden test set은 class 비율이 다르다. Other가 training data에서는 28.3 %이고 hidden test에서는 18.7 %다 ([Clifford 외, Table 2](https://www.physionet.org/files/challenge-2017/1.0.0/papers/065-469.pdf)).

같은 조건끼리 빼면 격차는 아래와 같다(추론: 표의 값끼리 뺀 것이고, Zihlmann의 네 class macro-F1은 class별 F1을 평균해 구했다).

| 비교 | Zihlmann 단일 model | 연구실 query population LIF | 격차 |
|---|---|---|---|
| 공식 점수, augmentation 없음 | 74.6–75.8 | 67.73 | 6.9–8.1점 |
| 공식 점수, augmentation 있음 | 79.0–79.2 | 67.73 | 11.3–11.5점 |
| 네 class macro-F1, augmentation 없음 | 69.7–71.7 | 62.36 | 7.3–9.3점 |
| 네 class macro-F1, augmentation 있음 | 75.6 | 62.36 | 13.2점 |
| (참고) hidden test 우승 점수 | 82.5–83.1 | — | 같은 조건이 아니다 |

결론은 이렇다. 실제 격차는 15점이 아니라 **약 7–12점**이다. 그래도 작지 않다. 이 비교에는 맞추지 못한 점이 있다. fold를 나눈 방식이 서로 다르다. Zihlmann의 model은 log spectrogram 위의 24-layer network이고, parameter 수는 노트에서 확인하지 못했다. 연구실 기록에 보이는 augmentation은 학습 때 무작위 30초 자르기뿐이다(다른 것이 없는지는 code로 다시 확인하지 않았다) ([MODI 기록 10-19](../../docs/MODI_PROJECT_LOG.md)).

CinC에는 비교할 만한 SNN baseline이 없다. 발표된 SNN 수치는 모두 공식 점수가 아니라 accuracy다. ANN을 SNN으로 바꾼 model이 84.4 %와 85.8 %, reservoir(학습하지 않는 recurrent 층) SNN이 78.5 %다 ([SNN survey, arXiv 2025](https://arxiv.org/abs/2506.01737); [Rana 외, Sensors 2024](https://doi.org/10.3390/s24113426)). Normal이 59.5 %인 data라서 accuracy는 Normal class가 좌우한다. 연구실 점수와 견줄 수 없다(추론). 같은 survey는 한 논문의 값을 본문에서 92 %, 표에서 78.5 %로 다르게 적었다. top machine learning 학회의 CinC 2017 SNN 논문은 찾지 못했다. 연구실의 10월 조사에서도 top-tier 전문 181편 가운데 CinC 2017이나 AFDB로 자기 model을 평가한 논문은 7편뿐이었다 ([MODI 기록 10-19](../../docs/MODI_PROJECT_LOG.md)).

문헌은 CinC가 순서를 요구한다고 말하지 않는다. 주최 측은 "feature를 잘 고른 random forest가 더 복잡한 방법만큼 잘했다"고 썼다. 박동 간격 통계 같은 순서 없는 요약으로 label의 대부분이 풀린다는 뜻이다(추론). label 자체도 흔들린다. 가장 논란이 된 test record 1,129개에서 annotator 사이 일치도 κ(우연을 뺀 일치 정도)는 0.245였다 ([Clifford 외, Table 1](https://www.physionet.org/files/challenge-2017/1.0.0/papers/065-469.pdf)).

그런데 CinC는 "섞어서 재학습" 결과가 있는 유일한 실제 dataset이기도 하다. 그 결과는 연구실 것이다. Spikformer식은 token 순서를 섞어 학습해도 점수가 같았다(−0.06 %p, fold 0) ([MODI 기록 10-29](../../docs/MODI_PROJECT_LOG.md)). query population model에서는 Neocortex의 입력 순서만 섞어 학습하면 점수가 떨어졌다. 다섯 fold 평균으로 순서의 몫은 **+1.65 %p(population LIF), +1.25 %p(population f-LIF)**다. memory 전체의 몫은 +2.40 / +1.37 %p이고, 순서 없는 축적의 몫은 +0.74 / +0.12 %p다. 이득은 주로 AF F1에서 나왔고 Noisy F1은 떨어졌다 ([MODI 기록 11-03](../../docs/MODI_PROJECT_LOG.md)). 그래서 CinC에서 쓸 수 있는 문장은 "attention은 순서에서 얻지 못한 약 1.3–1.7 %p를 Neocortex가 얻는다"까지다(추론). main result가 되기에는 효과가 작고 절대 수준이 낮다.

CinC를 계속 쓴다면 보고 방식은 정해져 있다(추론). 5-fold 공식 점수로 적는다. 같은 조건의 deep baseline으로 Zihlmann의 5-fold 행(74.6–79.2)을 인용한다. 0.83은 "hidden test의 ensemble 수준"이라고 이름 붙여 따로 적는다. 작은 model의 수치는 검색 요약으로만 보았고 확인하지 못했다. feature 위의 작은 dense network가 5-fold F1 약 0.804라는 것([PMC6377428](https://pmc.ncbi.nlm.nih.gov/articles/PMC6377428))과 1-D CNN이 F1 78.2 %라는 것([PMC7180882](https://pmc.ncbi.nlm.nih.gov/articles/PMC7180882))이다.

## ETT·MIT-BIH·anomaly detection: 표준 benchmark는 가까운 순서와 주기만 요구한다

ETT 쪽은 문헌 근거가 뚜렷하다. 입력을 통째로 섞으면 크게 나빠진다. 하지만 먼 과거의 배열은 거의 쓰이지 않는다. attention 몸통은 순서에 둔하다. 순서는 주로 출력 head가 token의 자리를 읽어서 쓴다.

| 시험 | 결과 | 읽는 법 | 출처 |
|---|---|---|---|
| 입력 전체 shuffle / 앞뒤 절반 맞바꾸기 (ETTh1, look-back 96) | Linear +81.06 % / +4.78 %, FEDformer +73.28 / +3.44, Autoformer +56.91 / +0.46, Informer +1.98 / +0.18 (MSE 평균 증가) | 가까운 순서만 중요하다 | [Zeng 외, AAAI 2023, Table 5](https://arxiv.org/pdf/2205.13504) |
| 오래된 절반만 shuffle (ETTh1, horizon 96) | +3.3–12.1 % (전체 shuffle은 +50.3–68.5 %) | 먼 쪽의 배열은 거의 안 쓴다 | [Tan 외, NeurIPS 2024, Table 6](https://arxiv.org/abs/2406.16964) |
| 입력 창을 96 step 과거로 옮김 (horizon 720) | FEDformer MSE: Electricity 0.251 → 0.265, Traffic 0.631 → 0.645 | 추세와 주기만 잡으면 된다(저자 해석) | [Zeng 외, Table 3](https://arxiv.org/pdf/2205.13504) |
| 학습된 PatchTST의 positional encoding을 0으로 | MSE 0.142 → 0.142 (image용 ViT는 89.8 → 32.4 %) | flatten 뒤 linear head가 token 자리를 읽는다 | [Liang 외, Table 2](https://arxiv.org/abs/2509.20942) (arXiv만) |
| Spikformer: positional encoding 없음 / 상대 위치 / CPG-PE(그 논문이 제안한 spiking positional encoding) | 평균 R² .719 / .733 / .744. 순서가 내장된 SpikeRNN은 없이도 .768 | 순서 정보의 값이 작다 | [CPG-PE, NeurIPS 2024, Table 1](https://arxiv.org/abs/2405.14362) |
| SpikF: 입력 shuffle | 바른 순서의 이득이 MAE 0.8 % | 같은 방향 | [SpikF, ICML 2025, App. A.1](https://proceedings.mlr.press/v267/wu25m.html) |
| look-back 96 → 336 → 720 (PatchTST, horizon 96) | ETTh2 0.294 → 0.274 → 0.279, ETTm2 0.178 → 0.165 → 0.162, Electricity 0.174 → 0.130 → 0.130, Traffic 0.477 → 0.367 → 0.365 | ETT의 이득은 5–10 %이고, 720이 336보다 낫지 않은 경우가 많다 | [PatchTST, ICLR 2023, Table 9](https://ar5iv.labs.arxiv.org/html/2211.14730) |

이 표에는 약점이 둘 있다. Zeng 외와 Tan 외는 섞은 data로 다시 학습했는지 본문에 적지 않았다. test 때만 섞은 시험으로 읽힌다. 그리고 "ETT는 긴 입력이 소용없다"는 말은 지나치다. PatchTST는 ETTh2·ETTm2에서 look-back 96 → 336으로 MSE가 7–8 % 낮아졌다(추론: 표의 값으로 계산). SpikF도 입력 48 → 720에서 MSE가 평균 9.0 % 좋아졌다 ([SpikF, Sec. 4.3](https://proceedings.mlr.press/v267/wu25m.html)). 긴 입력의 이득은 model과 tuning에 달려 있고, ETT에서는 절대 크기가 작다(추론). 이득의 정체는 주기다. benchmark의 주기를 직접 쓰는 model은 parameter 1,000개 미만으로도 겨룬다 ([SparseTSF](https://arxiv.org/html/2405.00946)).

연구실 기록은 이 문헌과 같은 방향이다. ETT에서 몸통의 token 순서를 섞으면 test MSE가 +0.30 % / +0.91 %만 나빠졌다. head까지 섞으면 모든 model이 +21 % 나빠졌다 ([MODI 기록 11-20](../../docs/MODI_PROJECT_LOG.md)). 입력을 336, 720으로 늘려도 Spikformer식과의 격차는 커지지 않았다 ([MODI 기록 11-17, 11-18](../../docs/MODI_PROJECT_LOG.md)).

MIT-BIH 쪽은 근거가 간접적이다. 박동 classification에 shuffle 시험을 한 논문은 찾지 못했다. 간접 근거는 세 가지다. 첫째, 12-lead ECG에서는 "3초 너머의 장기 의존성이 없다"는 결과가 있다. PTB-XL에서 점수는 입력 2–3초 근처에서 가장 높았다. 저자들은 급격한 rhythm 변화가 있는 장시간 ECG에는 이 결론이 미치지 않는다고 덧붙였다 ([Mehari & Strodthoff, ML4H 2022](https://arxiv.org/abs/2211.07579)). 둘째, 미리 잘라 정렬해 둔 시계열에서는 "time step이 feature가 된다" ([Swelam 외 2026](https://arxiv.org/abs/2611.09843), NeurIPS 2026 workshop·arXiv). UCR의 112개 dataset 가운데 약 3분의 1(classifier 두 종류 기준으로 MiniRocket 38개, catch22 36개)은 고정 순열을 걸어도 accuracy가 오차 범위 안이었다 ([Zhang 외 2025](https://arxiv.org/abs/2503.20264)). 평균과 표준편차 두 값만으로도 128개 가운데 69개에서 우연 수준을 넘었다 ([Henderson 외 2023](https://arxiv.org/abs/2303.17809), arXiv만). 셋째, 순서가 필요한 것은 박동 하나가 아니라 이웃 박동이다. 조기 심방 수축은 모양이 정상 박동과 같고 "너무 일찍 온다"는 점만 다르다. 그래서 model은 이웃 박동의 feature를 만들어야 한다 ([Icentia11k 논문](https://arxiv.org/abs/1910.09570)). 연구실의 MIT-BIH 설정은 박동 하나(187 sample, token 11개)다. 이웃이 입력에 없으니 순서가 도울 자리가 없다(추론). 기록도 같다. 순서를 못 보는 Spikformer(DE)가 MIT-BIH에서 macro-F1 91.27 %를 냈다 ([MODI 기록 11-19](../../docs/MODI_PROJECT_LOG.md)).

anomaly detection에서는 Neocortex의 이득을 기대하기 어렵다. 지금 가장 믿을 만한 평가는 TSB-AD다. 여기서 시점 하나씩만 보는 PCA(주성분 분석)가 신경망과 같은 점수를 낸다. 다변량 쪽 평균 VUS-PR(TSB-AD가 가장 안정적이라고 고른 평가 척도)은 PCA 0.31, CNN 0.31, LSTM 계열 0.31이고 Transformer 계열은 0.12–0.19다 ([TSB-AD, NeurIPS 2024, Table 5](https://proceedings.neurips.cc/paper_files/paper/2024/file/c3f3c690b7a99fba16d0efd35cb83b2c-Paper-Datasets_and_Benchmarks_Track.pdf)). 예전 평가 관행에서는 무작위 점수도 최고 성능이 될 수 있었다 ([Kim 외, AAAI 2022](https://ar5iv.labs.arxiv.org/html/2109.05257)). anomaly detection은 TSB-AD와 VUS-PR로 보고하되, 순서의 근거로는 쓰지 않는 것이 맞다(추론).

이론도 같은 말을 한다. recurrent state가 꼭 필요하다고 보인 과제는 입력이 올 때마다 누적 결과를 갱신해야 하는 계산이다. 길이를 늘려 test 한 accuracy가 Parity Check에서 RNN 100.0, LSTM 100.0, Transformer 52.0이었다. Cycle Navigation은 100.0 / 100.0 / 61.9였다. 이 두 과제는 입력을 섞어도 답이 같다. 축적은 필요하지만 순서는 필요 없는 과제다 ([Delétang 외, ICLR 2023, Table 2](https://arxiv.org/abs/2207.02098)). 반대로 색인으로 값을 꺼내는 과제는 attention이 유리하다 ([Bhattamishra 외, NeurIPS 2024](https://arxiv.org/abs/2406.09347)). label이 token에서 정보를 꺼내 모으는 함수이면 attention으로 충분하다. label이 token 흐름을 순서대로 갱신한 결과일 때만 순차 경로가 앞설 수 있다. 실제 신호 benchmark 가운데 그런 구조가 있다고 발표된 것은 없다(추론).

## 후보 검토: 발표된 근거는 축적까지 있고 순서는 없다

모든 후보에 걸리는 나쁜 소식 두 가지를 먼저 적는다. 첫째, 어느 후보에도 표본별 shuffle 재학습 결과가 발표돼 있지 않다. Sleep-EDF, PTB-XL, CPSC 2018, CinC 2017, CHB-MIT, CAPTURE-24, raw Speech Commands, QTDB, UEA, PPG-DaLiA, NSA 과제 모두 그렇다. 둘째, 연구실이 SHD를 뺀 이유는 다른 benchmark에도 약하게 적용된다. recurrent SNN 논문은 pixel, sample, frame을 spiking step 하나에 하나씩 넣는 것이 기본이다. S-MNIST는 784 step, Google Speech Commands는 Mel frame 101 step, NSA 과제는 200–500 step이다 ([Ma 외, Table I](https://arxiv.org/abs/2502.09449); [NSA, Table 1](https://arxiv.org/abs/2505.22035)). 예외는 Transformer형과 TCN형 SNN이다. 이들은 원래 입력 step마다 여러 번 반복해 돌린다. 반복을 1번으로 줄이면 Spike-Driven Transformer는 PS-MNIST에서 96.21 → 95.01, binary adding(표시된 자리의 값을 더하는 합성 과제)에서 98.15 → 88.05로 떨어졌다 ([Ma 외, Table VI](https://arxiv.org/abs/2502.09449)). 따라서 novelty 문장은 "순차 경로가 token당 spiking step 하나로 도는 Transformer형 SNN"이 되어야 한다. 비교 상대에는 Spikformer만이 아니라 state를 나르는 SNN(PMSN, Binary S4D, SpikingSSM)이 들어가야 한다(추론).

### Google Speech Commands: baseline은 가장 튼튼하고 순서 근거는 없다

이 dataset에는 ICLR 수준의 DNN과 SNN baseline이 같은 고정 split 위에 있다. raw 파형 16,000 step 입력에서 S4가 10 class 98.32 %, parameter 280 K의 S5가 35 class 96.52 %다 ([S4, ICLR 2022, Table 5](https://arxiv.org/abs/2111.00396); [S5, ICLR 2023, Table 2](https://arxiv.org/abs/2208.04933)). SNN은 P-SpikeSSM이 95.6 % / 96.23 %다. 이 model은 GELU activation을 쓴다고 표에 스스로 표시했다 ([P-SpikeSSM, ICLR 2025](https://arxiv.org/abs/2406.02923)). Mel frame(소리를 짧은 구간마다 주파수별 세기로 바꾼 것)을 spiking step 하나에 하나씩 넣는 설정에서는 196.5 K parameter의 TC-LIF가 94.84 %다(class 수는 다시 확인하지 못했다) ([TC-LIF, AAAI 2024, Table 1](https://arxiv.org/abs/2308.13250)). 축적 근거는 둘이다. memory-less control에서 92.91 → 77.53으로 떨어졌다 ([Ma 외, Table I](https://arxiv.org/abs/2502.09449)). 그리고 같은 model에 spiking self-attention을 바꿔 넣은 Spikformer식 변형은 93.38 %였고, state를 나르는 Spiking LMUFormer는 **96.12 %**였다 ([LMUFormer, ICLR 2024, Table 2](https://arxiv.org/abs/2402.04882)). 연구실의 비교(Hippocampus 대 Neocortex)와 가장 닮은 발표 수치다. 반대 근거도 분명하다. 시간 방향 gradient만 끊으면 89.00으로, 3.9점만 떨어진다. Ma 외는 이런 음성 dataset이 시간 처리 능력을 평가하는 데 효과적이지 않다고 결론 냈다. Spiking LMUFormer는 입력의 68 %(128 가운데 87)만 보고도 성능의 99 %를 냈다 ([LMUFormer, Sec. 5.5](https://arxiv.org/abs/2402.04882)). raw 16,000 step에서 attention 계열이 무너진다는 결과(Performer 30.77 %)는 길이 탓이다. patch token으로 줄이면 사라질 근거다(추론). 64-sample patch면 clip당 250 token이다(추론: 나눗셈).

### Sleep-EDF: 축적은 가장 잘 측정됐지만 10–15조각에서 멈춘다

수면 단계 classification은 밤새 잰 EEG를 30초 조각(수면 epoch)으로 나눠 조각마다 다섯 단계 가운데 하나를 맞힌다. 이웃 조각을 함께 주면 좋아진다는 것이 여러 번 측정됐다. MASS(다른 수면 dataset)에서 조각 하나만 보는 model의 MF1은 78.4, 조각 열을 보는 SeqSleepNet은 83.3이다 ([SeqSleepNet, IEEE TNSRE 2019](https://arxiv.org/abs/1809.10932)). SNN에서도 같은 방향이다. 전체 model이 accuracy 74.2 % / MF1 70.5, 조각 사이로 state를 넘기는 부분을 빼면 70.2 / 67.8, 이웃 조각을 아예 안 보면 64.8 / 62.7이다 ([NeuroSleep](https://arxiv.org/abs/2602.15888), arXiv만). SNN baseline과 DNN 사이에는 빈자리가 있다. SNN은 MF1 68–75, DNN은 0.79–0.80이다 ([PicoSleepNet, IEEE JBHI 2025](https://doi.org/10.1109/jbhi.2025.3602502), 초록만; [Wang & Strodthoff 2024, Table I](https://arxiv.org/abs/2402.17779), arXiv). 나쁜 소식은 셋이다. 이득이 조각 10–15개에서 멈춘다. 10개에서 200개로 늘려도 MF1은 0.790–0.796이다(같은 출처). 이웃 조각의 순서를 섞어 본 논문이 없다. 그리고 이득이 "수면 단계는 잘 안 바뀐다"는 성질만 쓴 smoothing일 수 있다. 비슷한 과제인 CAPTURE-24에서는 HMM만 얹어도 κ가 .704에서 .814로 올랐다 ([CAPTURE-24](https://arxiv.org/abs/2402.19229)). 수면 단계의 전이에는 방향이 있다. 그래서 이웃 조각을 섞는 시험은 값싸고 새롭지만, 결과는 문헌에서 미리 알 수 없다(추론). 비용 쪽으로는 조각 하나가 약 47 token, 15조각이 약 700 token이다(추론: 연구실 patch 크기로 나눈 값).

### WISDM-HAR와 OpenBMI EEG-MI: 연구실 주장과 가장 가까운 표가 있지만 SNN 전용이다

NSA(Neuromorphic Sequential Arena, IJCAI 2025)는 과제를 내놓기 전에 memory-less control로 과제부터 확인했다. 스마트워치 자이로 신호의 활동 인식(WISDM, 200 step, 18 class)은 81.27 → 67.75, EEG 운동 상상 classification(OpenBMI, 500 step)은 65.20 → 52.48로 떨어졌다 ([NSA, Table 2](https://arxiv.org/abs/2505.22035)). model별 표도 있다. 입력 반복 없이 돌린 Spike-Driven Transformer는 활동 인식에서 71.07로 가장 낮았다. state를 나르는 Binary S4D는 89.37, PMSN은 88.31이었다. EEG에서는 69.12 대 78.61 / 75.00이었다(NSA, Table 3–4). 모든 model이 약 0.1 M parameter다. 약점은 넷이다. memory-less control을 한 model에는 attention이 없었다. 그래서 "과거가 필요하다"만 보였고 "state가 모든 token을 보는 attention을 이긴다"는 보이지 못했다(추론). NSA 표에는 DNN 행이 없다. 활동 인식은 겹치는 창을 모든 사람에게서 모아 섞은 뒤 train과 test로 나눴다. 시계열 reviewer가 누출로 지적할 수 있다(추론). 그리고 순서 근거가 없다.

### QTDB, CAPTURE-24, 영장류 운동: 조건 하나씩이 빠진다

QTDB 파형 labeling은 ECG의 매 step이 여섯 구간(P, PQ, QR, RS, ST, TP) 가운데 어디인지 맞힌다. 답이 바로 앞에 무엇이 왔는지에 달려 있어서 가까운 순서가 정의상 필요하다. 같은 크기(1.8 K parameter)에서 LIF는 77.8 ± 1.85, adaptive neuron은 86.88 ± 0.40이다 ([SE-adLIF, Nat. Commun. 2025, Table 2](https://arxiv.org/abs/2408.07517)). SNN baseline이 Nature Machine Intelligence, ICML, Nature Communications에 이어져 있다 ([Yin 외](https://arxiv.org/abs/2103.12593); [Higuchi 외, ICML 2024](https://arxiv.org/abs/2402.14603)). 그러나 범위가 박동 하나(1,300 ms)라 긴 축적이 없다. DNN baseline은 작은 RNN뿐이고, 가장 높은 것이 Bi-LSTM의 80.76이다 ([Yin 외 2020](https://arxiv.org/abs/2005.11633)). CAPTURE-24는 축적 효과가 가장 크게 측정됐지만 그 정체가 smoothing이다. random forest에 HMM을 얹은 것(MF1 .789)이 창 8개를 보는 RNN(.776)보다 높다 ([CAPTURE-24, Table 5](https://arxiv.org/abs/2402.19229)). SNN baseline도 찾지 못했다. NeuroBench의 영장류 운동 prediction은 "neuron state가 흐름을 쌓는다"가 baseline 설계 자체인 유일한 곳이다. 입력을 하나씩 받는 LIF network가 최근 50 sample을 한꺼번에 받는 network와 같은 R² 0.593을 냈다 ([NeuroBench, Nat. Commun. 2025, Table 4](https://arxiv.org/abs/2304.04640)). 다만 필요한 과거가 50 sample, 0.2초다. "state가 입력 창을 대신한다"는 근거이지 "긴 과거가 필요하다"는 근거가 아니다(추론).

### Electricity와 Traffic: 긴 과거는 확실히 돕지만 주기 때문이다

forecasting 안에서는 Electricity와 Traffic이 긴 과거에 가장 크게 보상한다. PatchTST의 MSE가 look-back 96 → 336에서 horizon 96 기준 23–25 %, horizon 720 기준 15–16 % 낮아졌다. ETTh1·ETTh2는 5–8 %였다 ([PatchTST, Table 9](https://ar5iv.labs.arxiv.org/html/2211.14730)). spiking baseline도 있다. SpikF의 평균 MSE는 Electricity 0.183(iTransformer 0.178), Traffic 0.497(iTransformer 0.428)이다 ([SpikF, ICML 2025, Table 1](https://proceedings.mlr.press/v267/wu25m.html)). 약점은 이득이 336에서 멈추고(Traffic 0.367 → 0.365, Electricity 0.130 → 0.130), Traffic에서 linear model이 하루(24)와 한 주(168)의 배수 시차에 큰 가중치를 둔다는 점이다 ([Zeng 외](https://arxiv.org/pdf/2205.13504)). 끝없이 쌓는 축적이 아니라 주기 한 번을 덮는 효과다(추론). ETT에서 본 "순서는 head가 읽는다"가 그대로 되풀이될 위험이 크다(추론). Electricity가 Traffic보다 낫다. 변수가 321개로 더 적고, SpikF가 DNN에 가깝다(추론).

### 보류 중이거나 이미 다룬 것: PPG-DaLiA와 EigenWorms

PPG-DaLiA는 보류를 풀 근거가 새로 나오지 않았다. 오히려 목표가 올라갔다. 같은 평가 규칙에서 SNN인 PMSN이 MSE 5.17 ± 0.53(×10⁻²)을 보고했다. 비spiking 최고는 LinOSS-IM의 6.4다 ([PMSN, IEEE TNNLS 2026 채택, Table V](https://arxiv.org/abs/2408.14917)). spiking state-space model(선형 recurrent state로 긴 입력을 다루는 model)인 SHaRe-SSM은 9.1 ± 0.2다 ([SHaRe-SSM](https://arxiv.org/abs/2510.14386), arXiv판에서 읽음). EigenWorms는 순서 주장에 맞지 않는다는 근거가 더 쌓였다. 이 dataset의 "아주 긴 의존성" 근거로 인용되는 논문에서부터, 무작위로 고른 부분 입력이 같은 길이의 마지막 부분보다 높았다. 저자들은 정보가 전체에 고르게 퍼져 있다고 읽었다 ([UnICORNN, ICML 2021, Fig. 3](https://arxiv.org/abs/2103.05487)). 이것은 순서가 아니라 "많이 보기"의 모습이다(추론). 시간축 전체를 pooling 하는 ROCKET이 86.28 %, 구간 통계를 쓰는 CIF가 90.33 %다 ([Ruiz 외, DMKD 2021, Table 11](https://link.springer.com/content/pdf/10.1007/s10618-020-00727-3.pdf)). sequence model들은 70.9–95.0 %이고 seed 편차가 ± 16까지 간다 ([Log-NCDE, ICML 2024, Table 1](https://arxiv.org/abs/2402.18512); [LinOSS, ICLR 2025](https://arxiv.org/abs/2410.03943)).

## 입증 방법: 섞어서 재학습하고, 순서와 축적을 따로 보인다

받아들여지는 원칙은 하나다. "과제가 순서를 요구한다"는 섞은 data로 **다시 학습해서** 보인다. 정보를 지우는 시험을 재학습 없이 하면, 점수 하락이 정보가 없어져서인지 처음 보는 입력이라서인지 알 수 없다 ([ROAR, NeurIPS 2019](https://arxiv.org/abs/1806.10758)). 언어 쪽에서도 "학습과 평가 모두에서 지우기"와 "평가 때만 지우기"는 서로 다른 것을 잰다고 정리돼 있다 ([O'Connor & Andreas](https://arxiv.org/abs/2106.08367)). benchmark를 이 시험으로 고른 선례는 video에 있다. frame을 섞어 학습하면 Something-Something에서는 차이가 컸고 UCF101에서는 없었다. 저자들은 UCF101이 시간 추론을 요구하지 않는다고 결론 냈다 ([TRN, ECCV 2018](https://arxiv.org/abs/1711.08496)). 연구실 기록도 같은 것을 보여 준다. CinC에서 test 때만 섞었을 때의 하락(9.25–17.50 %p)은 대부분 처음 보는 입력 탓이었다 ([MODI 기록 10-29](../../docs/MODI_PROJECT_LOG.md)).

세 성질은 따로 보여야 한다. 긴 context(잘라내기), 순서(표본별 shuffle 재학습), state 안의 축적(memory-less control)이다. memory-less control에서 무너져도 순서와 무관한 과제가 있다. 더하기나 XOR이 그렇다(추론). 아래 표가 대조 구성이다.

| 대조 | 무엇을 보이나 | 선례 | 함정 | 연구실 현황 (CinC) |
|---|---|---|---|---|
| 1. 잘라내기: 마지막 k개와 무작위 k개 | 긴 context가 필요한가. 무작위 k개가 더 좋으면 순서가 아니라 "많이 보기"다 | [UnICORNN, Fig. 3](https://arxiv.org/abs/2103.05487) | 잘라내기만으로는 memory의 근거가 약하다 | 마지막 k개는 했다(마지막 4초만 주면 −6.1 %p). 무작위 k개는 not run |
| 2. 표본별 shuffle 재학습, block 크기별로도 | 과제가 순서에 보상하는가. 어느 길이에서 순서가 중요한가 | [ROAR](https://arxiv.org/abs/1806.10758), [TRN](https://arxiv.org/abs/1711.08496) | 고정 순열은 다른 시험이다. 섞는 단계에 따라 순서가 샌다([Abdou 외, ACL 2022](https://arxiv.org/abs/2203.10995)) | 했다. Spikformer식 −0.06 %p, Neocortex 입력만 섞으면 −1.65 / −1.25 %p. block 크기별은 not run |
| 3. 순서를 못 보는 baseline | 같은 token으로 순서 없이 어디까지 가는가 | spike 수만 쓴 SVM([Cramer 외, IEEE TNNLS](https://arxiv.org/abs/1910.07407)), 평균·표준편차([Henderson 외](https://arxiv.org/abs/2303.17809)) | "positional encoding을 뺐으니 순서를 못 본다"고 가정하면 안 된다 | CinC의 Spikformer식에는 상대 위치 bias가 있었다. bias 없는 판은 not run |
| 4. memory-less control, parameter 수 같게 | 축적이 state에 있는가 | NoTD([Ma 외](https://arxiv.org/abs/2502.09449)), reset 제거([PSN, NeurIPS 2023](https://arxiv.org/abs/2304.12760)) | 순서는 못 가른다 | 했다. +2.40 / +1.37 %p. 다만 population Neocortex가 memory를 끄면 거의 발화하지 않아(0.1 % / 0.7 %) 깨끗한 대조가 아니다 |
| 5. attention에 positional encoding을 준 model | 이득이 "순서 정보"에서 오는가 "순차 memory"에서 오는가 | 같은 크기의 무작위 encoding 행([CPG-PE, Table 2](https://arxiv.org/abs/2405.14362)) | 이 model이 격차를 메우면 주장이 바뀐다 | 상대 위치 bias가 있는 Spikformer식은 순서를 쓰지 못했다(섞어 학습해도 같은 점수) |
| 6. 경로 나누기: Neocortex만, Hippocampus만, 둘 다 | 이득이 어느 경로의 것인가 | 구성 요소 제거 표([Sun 외, Nat. Mach. Intell. 2026](https://arxiv.org/abs/2512.07602)) | parameter 수를 맞춘다 | 일부 했다 |
| 7. smoothing 대조 (조각별 label 과제만) | 이득이 label이 이어지는 성질에서 오는가 | [CAPTURE-24](https://arxiv.org/abs/2402.19229) | Sleep-EDF와 CAPTURE-24에서는 필수다 | 해당 없음 |

3번의 함정은 구체적으로 알려져 있다. positional encoding을 빼도 순서가 새는 길이 넷이다. 미래를 가리는 causal mask([Haviv 외, Findings of EMNLP 2022](https://arxiv.org/abs/2203.16634)), flatten 뒤의 linear head([Liang 외](https://arxiv.org/abs/2509.20942), arXiv만), convolution의 padding([Islam 외, ICLR 2020](https://arxiv.org/abs/2001.08248), 초록만), 그리고 token당 step 하나인 spiking model에서는 neuron state 자체다(추론). 그래서 "순서를 못 본다"는 가정하지 말고 시험해야 한다. 입력 token을 섞었을 때 출력이 정확히 같은지 확인하면 된다. 연구실은 ETT에서 이미 이 확인을 했다. bias 없는 Spikformer(DE)는 몸통을 섞어도 변화가 정확히 0이었다 ([MODI 기록 11-20](../../docs/MODI_PROJECT_LOG.md)).

결과에 따라 쓸 수 있는 문장이 달라진다(추론).

| 결과 | 쓸 수 있는 문장 |
|---|---|
| 순서를 못 보는 baseline이 섞어 학습한 model과 같고, 원본으로 학습한 model들도 같다 | 이 과제는 순서에 보상하지 않는다. main result에서 뺀다 |
| Neocortex model만 섞으면 떨어지고, positional encoding을 준 attention은 따라오지 못한다 | Neocortex는 positional encoding으로 얻지 못하는 순서 정보를 쓴다 |
| positional encoding을 준 attention이 격차를 메운다 | 순차 memory가 필요한 것이 아니다. 주장은 "positional encoding 없이 순서 정보를 얻는다"로 바뀌고, 값이 싼지는 energy로 보인다 |
| memory-less control에서만 떨어지고 shuffle에는 무관하다 | 축적만 보였다. "순서"는 주장할 수 없다 |

실제 benchmark만으로는 부족하다. SNN neuron 논문들은 요구 조건이 정의로 보장되는 구성 과제를 하나 둔다. DH-SNN은 두 단서 사이에 지연을 두고 XOR을 맞히는 과제를 만들었다. 표준 dataset의 accuracy만으로는 작동 원리를 알기 어렵다는 이유였다 ([DH-SNN, Nat. Commun. 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10766638/)). recurrent model 논문들은 실제 내용 32 step 뒤에 noise 968 step을 붙인 CIFAR-10을 쓴다 ([AntisymmetricRNN, ICLR 2019](https://arxiv.org/abs/1902.09689); [LEM, ICLR 2022](https://arxiv.org/abs/2110.04744)). 여기서 새로 확인된 점이 중요하다. **XOR과 더하기는 두 값을 바꿔도 답이 같다.** 축적만 요구하고 순서는 요구하지 않는다(추론). 이전 보고서가 제안한 지연 단서 ECG도 XOR이었다. 순서를 보이려면 변형이 하나 더 필요하다. 두 단서 조각의 순서를 바꾸면 답이 뒤집히는 과제다. 실제 생체 신호 위의 순서 맞히기는 자기지도 학습의 보조 과제로 선례가 있다. EEG 창 세 개가 순서대로인지 맞히기([Banville 외, J. Neural Eng. 2021](https://arxiv.org/abs/2007.16104)), 가속도 신호가 시간으로 뒤집혔는지 맞히기([Saeed 외, IMWUT 2019](https://arxiv.org/abs/1907.11879))다. 실제 생체 신호 조각을 단서로 쓴 지연 과제를 평가 benchmark로 쓴 심사 통과 논문은 찾지 못했다. 그 조합은 새것이다. 지연은 순서를 못 보는 baseline과 memory-less control이 우연 수준에 닿을 때까지 늘린다. TS-LIF의 표가 그 형식이다. LIF는 지연 10에서 0.748, 20부터 0.504였다 ([TS-LIF, ICLR 2025, Table 11](https://arxiv.org/abs/2503.05108)). 이 과제는 "진단"이라고 부르고 진단으로만 써야 한다. 만든 label을 실제 과제 결과처럼 보고하는 것이 UCR 비판의 한 항목이었다 ([Swelam 외 2026](https://arxiv.org/abs/2611.09843)).

reviewer가 무엇을 요구했는지도 기록이 있다(모두 review 요약이고 원문 확인이 필요하다). TS-LIF(ICLR 2025)의 한 reviewer는 forecasting 실험이 장기 의존성을 제대로 재는지 물었다. 저자는 지연 XOR 표로 답했고 논문은 채택됐다 ([OpenReview rDe9yQQYKt](https://openreview.net/forum?id=rDe9yQQYKt)). P-SpikeSSM(ICLR 2025)에는 PS-MNIST가 충분히 어렵지 않으니 sequential CIFAR를 더하라는 요구가 있었다. 이득이 제안한 neuron에서 오는지 state-space 구조에서 오는지 가르라는 요구도 있었다 ([OpenReview Sf4ep9Udjf](https://openreview.net/forum?id=Sf4ep9Udjf)). ICLR 2026의 새 neuron 투고는 PS-MNIST와 sequential CIFAR-10 결과를 이름으로 요구받았다 ([OpenReview 9W38INOZ00](https://openreview.net/forum?id=9W38INOZ00)). 시계열 쪽에서는 순서 바꿈을 학습과 test 모두에 적용한 투고가 "test 때만 섞는 함정을 피했다"는 평을 받았다. 동시에 순서 바꿈을 여러 개 독립으로 돌리라는 요구도 받았다 ([OpenReview 8vgP9VhECt](https://openreview.net/forum?id=8vgP9VhECt)). SNN 논문에 입력 shuffle 대조를 요구한 review는 찾지 못했다. 섞어서 재학습한 표와 memory-less control을 함께 내면 이 분야의 관행을 넘어선다(추론). 반대로 PS-MNIST, sequential CIFAR, Google Speech Commands는 넣지 않으면 이름으로 요구받을 가능성이 높다(추론).

## 추천 순위: 확인 시험을 먼저 돌릴 순서

이 순위는 "조건을 만족하는 순서"가 아니다. 만족이 확인된 후보는 없다. "어디에 확인 시험(위 표의 1–4번)을 먼저 돌릴 것인가"의 순서다. 기준은 baseline의 신뢰도와 작은 model의 도달 가능성, 발표된 축적 근거, 비용 순이다. CinC에서 문제가 된 것이 baseline과의 거리였기 때문이다. 순위 전체가 추론이다.

| 순위 | 과제 | 이 순위인 이유 | 통과해야 할 확인 | 가장 큰 위험 |
|---|---|---|---|---|
| 1 | Google Speech Commands | DNN·SNN baseline이 모두 ICLR 수준이고 0.2–0.3 M model이 최고 수준이다. memory-less control 결과(−15.4점)와 spiking attention 대 state model의 차이(93.38 대 96.12)가 발표돼 있다. reviewer가 이름으로 기대한다 | 표본별 shuffle 재학습, 순서를 못 보는 baseline | 점수가 상한에 가까워 Neocortex의 이득이 1–3점 안에 갇힌다. 입력 일부만으로 풀린다 |
| 2 | Sleep-EDF 수면 단계 | 생리 신호 가운데 축적이 가장 잘 측정됐다. SNN(MF1 68–75)과 DNN(0.79–0.80) 사이에 빈자리가 있다 | 이웃 조각 shuffle 재학습, smoothing 대조 | 이득이 smoothing으로 판명된다. SNN baseline은 초록만 본 것과 arXiv만 있는 것이다 |
| 3 | WISDM-HAR, OpenBMI EEG-MI (NSA 설정) | 실제 신호 가운데 memory-less control 결과가 발표된 드문 과제다. spiking Transformer가 가장 약하다는 표가 있다. 길이 200–500, 약 0.1 M으로 가볍다 | 표본별 shuffle 재학습, 사람 단위 분할로 다시 재기, DNN 행 추가 | SNN 전용 benchmark라 시계열 reviewer에게 약하다. 비교 상대가 강한 state-space SNN이다 |
| 4 | Electricity (Traffic은 선택), look-back 96 → 336 | forecasting 축에서 긴 과거의 이득이 가장 크게 발표됐다. spiking baseline이 있다 | head와 몸통을 나눈 shuffle, 입력 창 옮기기 | ETT처럼 순서를 head가 읽는 것으로 끝난다 |
| 5 | CinC 2017, 공식 점수로 재보고 | 섞어서 재학습한 결과가 이미 있는 유일한 실제 dataset이다 | 무작위 k개 잘라내기, block 크기별 shuffle, bias 없는 Spikformer식 | 격차 7–12점. 보조 근거 이상으로 쓰기 어렵다 |

1위와 2위의 순서는 baseline의 신뢰도를 더 무겁게 본 판단이다. classification 노트는 Sleep-EDF를 1위, Speech Commands를 2위로 두었다. 생리 신호를 main result로 삼고 싶다면 둘을 바꿔도 근거로는 손해가 없다. 이전 보고서는 raw Speech Commands를 "입력 일부로 풀리는 과제"라는 이유로 뺐다. 그 약점은 그대로다. 순위가 올라간 것은 memory-less control 결과와 Spikformer식 변형의 수치가 새로 확인됐기 때문이다.

순위와 별개로 함께 둘 것이 셋 있다(추론). 첫째는 순서 변형을 넣은 구성 과제다. 실제 benchmark에서 이득이 작게 나와도 작동 원리의 근거가 된다. 둘째는 QTDB다. 작고 SNN끼리 비교가 되므로 "가까운 순서를 쓴다"는 확인용으로 맞다. 셋째는 PS-MNIST와 pixel 단위 sequential CIFAR-10이다. 시계열은 아니지만 reviewer가 이름으로 요구한다. pixel 단위 sequential CIFAR-10에는 차이를 보일 자리가 남아 있다. 0.2 M 안팎에서 LIF 45.07, PMSN 82.14이고 DNN인 S4가 91.13이다 ([PMSN, Table III](https://arxiv.org/abs/2408.14917); [S4, Table 6](https://arxiv.org/abs/2111.00396)). pipeline이 이미 있어서 값싸게 확인할 것도 둘 있다. 이웃 박동을 함께 넣은 MIT-BIH(환자 단위 분할, 심방성 조기 박동 class)와, record 전체를 봐야 하는 CPSC 2021이다. 둘 다 baseline 수치를 확인하지 못했다. 이단맥(정상 박동과 조기 박동이 번갈아 오는 rhythm)처럼 박동의 순서로 정의되는 rhythm class도 원리로는 좋은 후보다. Stanford 연구에 그런 class가 있다 ([Hannun 외, Nat. Med. 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6784839/)). 하지만 shuffle 결과가 발표된 적이 없고 공개 data의 범위를 확인하지 못했다(추론).

## 결론

찾던 것이 없다는 사실이 가장 쓸모 있는 결과다. "이 benchmark는 순서와 축적을 요구한다"고 인용할 논문이 없다. 그러니 그 입증은 연구실의 몫이다. 그리고 그 입증 자체가 논문의 한 부분이 될 수 있다. SNN 분야에서 섞어서 재학습한 과제 확인 표를 낸 논문을 찾지 못했기 때문이다(추론). 연구실은 이미 그 표의 절반을 갖고 있다. CinC에서 Spikformer식은 순서를 섞어 학습해도 같은 점수였고, Neocortex는 순서에서 1.3–1.7 %p를 얻었다. ETT에서는 순서가 head에 있다는 것을 확인했다. 표준 benchmark의 "차이 없음"은 model의 약점이 아니라 benchmark의 성질로 기록할 수 있다.

주장의 모양은 5번 대조가 정한다(추론). 새 과제에서도 positional encoding을 준 attention이 Neocortex를 따라오지 못하면 "순차 memory가 필요하다"를 쓸 수 있다. 따라오면 주장은 "positional encoding 없이, 더 싼 값에 순서 정보를 얻는다"가 되고 무게가 energy로 옮겨 간다. 어느 쪽이든 절대 수준이 발표된 baseline 근처여야 main result가 된다. 그래서 0.2–0.3 M model이 최고 수준에 닿는 Speech Commands와 SNN baseline 위에 빈자리가 있는 Sleep-EDF가 CinC보다 낫다. 실제 과제의 이득이 얼마나 커야 reviewer가 받아들이는지는 이번 조사로 알 수 없었다. 구성 과제는 그 불확실성에 대한 대비다.
