# 어텐션을 가려야 뉴런 상태의 기억이 보인다

CinC보다 "더 긴" 데이터셋을 찾는 것만으로는 이 질문에 답할 수 없다. 2023–2026년 문헌은 일관되게 말한다. 어텐션(주의, attention)이 입력 전체를 볼 수 있으면 고정 크기 순환 상태가 따로 나를 정보는 거의 없다. 순환 상태가 이기는 경우는 세 가지다. 정보가 어텐션 창 밖에 있을 때, 학습 길이보다 긴 입력으로 외삽할 때, 그리고 입력을 받을 때마다 누적 결과를 갱신하는 계산(상태 추적)일 때다 ([Ni 외, NeurIPS 2023](https://arxiv.org/html/2307.03864v4); [De 외, Griffin](https://arxiv.org/html/2402.19427); [Merrill 외](https://arxiv.org/html/2404.08819)). 연속 신호 장기 벤치마크(UEA, PPG-DaLiA, 원시 Speech Commands)에서 잘라내기나 순서 섞기로 장기 기억 요구를 직접 보인 출판 결과는 찾지 못했다. 우리 기록도 같은 방향을 가리킨다. CinC에서 8토큰 → 117토큰으로 얻은 +22.5점 가운데 +17.7점은 토큰 섞기 모듈이 없는 하한 모델도 얻었다. 또 LIF 신피질의 영향은 10토큰(2.6초) 안에 거의 사라진다 ([MODI 기록](../docs/MODI_PROJECT_LOG.md)). 그래서 **과제 둘을 짝짓기를 권한다.** 1순위는 실제 ECG 위에 1비트 단서 두 개를 지연 Δ만큼 떨어뜨려 심은 반합성 **"지연 단서 ECG"**다. 어텐션 창을 Δ보다 좁혀 뉴런 상태를 유일한 통로로 만든다. 2순위는 **PPG-DaLiA 심박 회귀(Log-NCDE 프로토콜)**다. 스파이킹 기준값(PMSN 5.17, SHaRe-SSM 9.1; MSE×10⁻²)이 있고 2초마다 라벨이 있어 T = N에 맞는다. 다만 라벨이 8초 국소 심박이라 "긴 기억"이 아니라 "추적"까지만 주장할 수 있다. EigenWorms는 표준 대안이지만 작고 seed 편차가 크다. 지금 GPU에서 도는 ETT(24토큰)·MIT-BIH(11토큰) 실험은 너무 짧아 기억을 시험하지 못한다. 그 결과는 이 순위의 실행 순서와 대조군 구성만 바꾼다.

## 읽는 법과 용어

이 보고서는 두 종류의 문장을 나눈다. **확인**은 출처 링크가 붙은 사실이다. 외부 문헌이거나 우리 실험 기록(`docs/MODI_PROJECT_LOG.md`)이다. **판단**은 우리 쪽 추론과 제안이다. 문단 머리에 "판단"이라고 적거나 표 칸에 "(판단)"을 붙였다. 조사 노트에 출처 없이 적힌 수치는 쓰지 않았다. "초록만 확인"은 본문을 열지 못한 자료다. "찾지 못했다"는 검색 결과가 없었다는 뜻이지, 없다는 증명이 아니다.

| 용어 | 쉬운 뜻 |
|---|---|
| T = N | 토큰 하나를 스파이킹 시간 한 스텝에 맞춘다. 막전위가 토큰 사이로 정보를 나른다. |
| 기억 없는 대조 | 같은 신피질이지만 토큰마다 상태를 리셋한다(`--neo_memoryless`). 파라미터 수가 같다. |
| 도달 거리 | 입력 토큰 하나를 바꿨을 때 몇 토큰 뒤까지 출력 스파이크가 바뀌는지. 우리 `rhythm_analysis.py`의 측정이다. |
| 잘라내기 곡선 | 입력의 일부(마지막 k개, 처음 k개, 먼 구간 k개)만 남기고 잰 점수 곡선. 점수가 더 오르지 않는 최소 k가 과제가 실제로 쓰는 맥락 길이다. |
| 순서 섞기 / 섞기 재학습 | 토큰 순서를 섞어서 평가하거나, 섞은 데이터로 처음부터 학습한다. 섞어서 재학습해도 점수가 같으면 그 과제는 순서를 쓰지 않는다. |
| 평활 | 이웃 시점의 예측을 고르게 만드는 처리. HMM(은닉 마르코프 모델)은 "상태가 잘 안 바뀐다"는 사전지식으로 예측열을 고른다. 새 정보를 더하지 않고 라벨이 이어지는 성질만 쓴다. |
| 인과 창 어텐션 | 각 토큰이 자기와 바로 앞 W개 토큰만 보는 어텐션. |
| 수용 영역 R | 출력 하나가 볼 수 있는 입력 범위. 대략 층 수 × W에 패치 임베딩 폭을 더한 값이다. |
| 지연 Δ | 단서와 질의 사이의 토큰 수. |
| XOR | 두 비트가 다르면 1, 같으면 0. 한쪽 비트만 봐서는 맞힐 수 없다. |
| 신용 할당 길이 | 출력의 오차가 원인 입력까지 거슬러 가야 하는 거리. 끝에 라벨이 하나뿐이면 최대 N이다. |
| 조밀 감독 | 끝의 라벨 하나 대신 여러 시점에 정답을 준다. 신용 할당 길이가 짧아진다. |
| 선형 해독 | 막전위에서 선형 분류기로 과거 단서를 맞히는 정확도. 상태 안에 정보가 남아 있는지 보는 방법이다. |
| 상태 바꿔 끼우기 | 추론 중에 두 표본의 신피질 상태를 맞바꾸는 개입. 예측이 바뀐 상태를 따라가면 정보가 상태에 있었다는 인과적 증거다. |
| SSM | 상태 공간 모델. 선형 순환 상태로 긴 시퀀스를 다루는 모델 계열(S4, S5, LRU, LinOSS, Mamba). |
| Log-NCDE 프로토콜 | UEA 6종과 PPG-DaLiA를 같은 분할·시드·탐색 격자로 돌리는 2024년 공용 규칙. 2024–2026년 장기 시퀀스 논문 대부분이 따른다. |
| 사전 등록 | 실행 전에 조건, 대조군, 판정 규칙을 고정해 기록하는 것. |

## CinC의 무효 결과는 문헌과 우리 측정이 이미 예고했다

**확인 (문헌: 어텐션이 다 볼 때).** Ni 외는 "기억 길이"와 "신용 할당 길이"를 따로 정의했다. 전체 맥락을 보는 Transformer는 기억 길이 1,500인 T-미로를 풀었다. LSTM은 250에서 무너졌다. 신용 할당 길이가 250이면 둘 다 실패했다 ([Ni 외](https://arxiv.org/html/2307.03864v4)). 어텐션이 전부 볼 수 있으면 순수한 기억은 어텐션이 더 잘한다는 뜻이다. Griffin의 국소 어텐션(창 1,024토큰)은 전화번호부가 창 안에 있으면 완벽했고, 창을 넘자 성능이 떨어졌다 ([De 외](https://arxiv.org/html/2402.19427)). 1층 RNN은 순열을 차례로 곱하는 "군 단어 문제"를 임의 길이로 풀었다. Transformer·S4·Mamba는 길이가 늘수록 층이 더 필요했다 ([Merrill 외](https://arxiv.org/html/2404.08819)). 반대로 많은 정보를 정확히 꺼내야 하는 과제에서는 고정 상태가 이론적으로 진다. 상태 기억량이 L·log D − 1보다 작으면 길이 L 복사의 오류가 1/2을 넘는다 ([Jelassi 외](https://arxiv.org/html/2402.01032v2)). 게이트 합성곱 모델은 모델 차원이 시퀀스 길이 이상이어야 다중 키-값 회상(MQAR)을 풀었다 ([Arora 외](https://arxiv.org/html/2312.04927)).

**확인 (문헌: 스파이킹).** 짧은 시퀀스에서는 뉴런 종류의 차이가 작다. 열 단위 순차 CIFAR-10(32스텝)에서 리셋 없는 LIF 79.50, LIF 81.50, PLIF 83.49, PSN 88.45%였다 ([Fang 외, PSN, NeurIPS 2023](https://arxiv.org/abs/2304.12760)). 같은 영상을 화소 단위 1,024스텝으로 넣으면 **LIF 45.07, PSN 55.24, PMSN 82.14%**로 벌어진다(두 설정의 파라미터 수는 다르다) ([Chen 외, PMSN](https://arxiv.org/abs/2408.14917)). 지연 스파이킹 XOR에서 **LIF는 지연 10스텝 0.748, 20스텝부터 0.504 이하(우연 수준)**였다. TS-LIF는 20스텝 0.977, 40스텝 0.585였다 ([TS-LIF, ICLR 2025](https://arxiv.org/abs/2503.05108)).

**확인 (우리 기록).** CinC 9단계 관문에서 양방향 LIF Neo-mixer의 검증 점수는 8토큰 0.434, 117토큰 0.659였다(+22.5점). 그런데 **토큰 섞기 모듈이 없는 하한(`mix_none`)도 0.424에서 0.601로 올랐다(+17.7점)** ([MODI 기록 10-19 23:50](../docs/MODI_PROJECT_LOG.md)). 이 하한에 남은 토큰 사이 통로는 임베딩·MLP의 LIF 막전위(τ 2)와 마지막 토큰 평균뿐이다. 같은 단계의 도달 거리 측정에서 NSMT LIF 신피질은 **d = 5에서 4.49%, d = 10에서 1.65%, d = 50에서 0.01%**였다. population f-LIF 구성만 d = 50에서 3.4–4.9%를 유지했다(NSMT 4.92, Neo-mixer 3.42; population LIF는 9단계 뒤에 추가되어 도달 거리를 재지 않았다). 토큰 간격은 0.256초다 ([MODI 기록 10-20 16:18](../docs/MODI_PROJECT_LOG.md)). B 실험(Spikformer식에 T = N 신피질을 키·값으로 덧붙임)에서 기억 없는 신피질 덧붙임은 Spikformer식과 같았다(+0.24). LIF T = N은 기억 없는 대조보다 나빴다(−2.50, seed 3/3). population LIF 덧붙임(66.06)은 평균은 가장 높았지만 기억 없는 대조와 차이가 없었다(+0.23). 같은 날 A 실험에서는 Neo-mixer가 90 epoch에서 네 뉴런 모두 좋아졌다. T = N 모델이 30 epoch에는 덜 배운다는 뜻이다 ([MODI 기록 10-27 15:34](../docs/MODI_PROJECT_LOG.md)).

**판단.** 네 가지를 읽는다. 첫째, CinC 관문은 "긴 입력이 필요하다"를 보였지만 "순서나 기억이 필요하다"는 보이지 못했다. 이득의 약 4/5(17.7/22.5)는 토큰을 섞지 않고 평균만 내는 모델도 얻었다. 박동을 더 많이 보는 "증거 누적"으로 설명되는 몫이다. 심방세동 판별이 RR 간격의 불규칙성 같은 누적 통계로 풀릴 수 있다는 점과도 맞는다. 둘째, 117토큰 전체에 어텐션이 걸려 있어 상태만 나를 수 있는 정보가 없었다. 문헌이 예측하는 그대로다. 셋째, **LIF 상태는 애초에 10토큰(2.6초) 넘게 정보를 나르지 못한다.** LIF로 시험하면 어떤 과제에서든 "기억 기여 없음"이 기본 예측이다. 먼 거리 기억 후보는 population 계열뿐이다. 넷째, 끝 라벨이 하나라 신용 할당 길이가 최대 117이고, 학습 예산도 모자랐다. "기억이 필요 없음"과 "기억을 학습하지 못함"이 섞여 있다. 따라서 다음 단계는 데이터셋 교체가 아니라 **설계 교체**다. 어텐션이 못 보는 조건, 작은 정보를 오래 들고 있어야 하는 구조, 조밀 감독이 들어가야 한다.

### 1위 지연 단서 ECG는 기억 요구를 구성으로 보장한다

**확인.** DH-SNN은 지연 스파이킹 XOR에서 지연 값을 바꿔 가며 기억 길이를 쟀다. 두 발화율 패턴 사이에 잡음 섞인 지연을 두고, 두 패턴의 XOR을 맞히게 했다 ([Zheng 외, Nat Commun 2024](https://www.nature.com/articles/s41467-023-44614-z)). 같은 논문의 다중 시간척도 XOR은 질의가 올 때마다 첫 신호와의 XOR을 출력하게 해 조밀 감독 구조를 만든다 ([Europe PMC 전문](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC10766638/fullTextXML)). DelayNet 단서 누적 과제는 좌·우 단서 7개 뒤 500–1,500 ms를 기다려 회상하게 했고, 지연을 빼면 우연 수준을 넘지 못했다 ([DelayNet](https://arxiv.org/html/2310.19067)). 연속 입력 상태 추적의 선례로는 변위만 보고 속도를 추적해야 하는 SE-adLIF의 스프링-질량 과제가 있다 ([Baronig 외, Nat Commun 2025](https://arxiv.org/abs/2408.07517)). 어텐션 창 밖 정보에서 어텐션이 무너지는 선례는 Griffin이다 ([De 외](https://arxiv.org/html/2402.19427)).

**판단.** 기억 요구가 정의로 보장되는 유일한 후보다. 어텐션 창 W와 지연 Δ를 따로 조절할 수 있다. CinC 파이프라인(125 Hz, 64샘플 패치, 117토큰)을 그대로 쓴다. 단서 정보가 원래 리듬 라벨과 독립이라 "토큰 주머니"로는 풀 수 없다. 약점은 표준 벤치마크가 아니라는 점이다. 이것만으로는 "실제 신호에서 쓸모 있다"를 말할 수 없다. 그래서 2위와 짝지어야 한다.

### 2위 PPG-DaLiA는 T = N에 가장 잘 맞는 실제 신호다

**확인.** Log-NCDE 프로토콜은 15명(1인당 약 150분)의 손목 신호 6채널(혈류 맥파, 피부 전기, 온도, 가속도 3축)을 쓴다. 개인별로 70:15:15 연속 구간을 나누고, 길이 49,920·간격 4,992의 창을 만든다. 같은 분할에서 5회 돌린 MSE 평균으로 비교한다 ([Walker 외, Log-NCDE, ICML 2024](https://arxiv.org/html/2402.18512v3)). 코드는 모든 채널과 심박 라벨을 개인별 전체 기록 기준으로 [−1, 1]에 맞추고, 창마다 심박 390개(2초마다 하나)를 정답으로 둔다 ([process_ppg.py](https://github.com/Benjamin-Walker/log-neural-cdes/blob/main/data_dir/process_ppg.py)). 정답 심박은 가슴 ECG에서 구한 8초 창(2초 이동)의 평균 순간 심박이다 ([Reiss 외, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6679242/)). SSM들도 메모리 때문에 batch 4를 썼고 ([Log-NCDE](https://arxiv.org/html/2402.18512v3)), LinOSS는 이 과제만 A100에서 돌렸다 ([Rusch & Rus, LinOSS, ICLR 2025](https://arxiv.org/html/2410.03943)). 다른 프로토콜(LoSo, MAE BPM)에서는 맥락 효과가 직접 측정돼 있다. BeliefPPG 절제(5-fold)에서 최종 모델 3.59, 시간 방향 메시지 전달을 빼면 4.02, 8초 창 하나로 줄이면 4.86 BPM이었다 ([BeliefPPG](https://arxiv.org/pdf/2306.07730)). UEA·PPG에서 T = N 순환 경로를 스파이킹 자기 주의와 직접 비교한 SNN 논문은 찾지 못했다.

**판단.** 128샘플(2초)을 토큰 하나로 두면 창당 390토큰이고 토큰마다 라벨이 하나다. T = N에 정확히 맞고 조밀 감독이 저절로 생긴다. "직전 심박"은 몇 비트짜리 정보를 계속 갱신하는 구조라, 문헌상 순환 상태가 유리한 쪽에 속한다. 비스파이킹·스파이킹 기준값이 모두 있다. 약점은 두 가지다. 라벨이 8초 국소라, 이득이 나도 "긴 기억"이 아니라 "추적·시간 사전정보"다. 또 BeliefPPG의 메시지 전달 이득(4.02 → 3.59) 자체가 평활 계열이다. 그래서 평활 대조가 필수다.

### 3위 EigenWorms는 비교 표준은 확실하지만 잡음이 크다

**확인.** EigenWorms는 예쁜꼬마선충 자세 영상을 6개 기본 모양에 투영한 6채널 17,984스텝 시계열이고, 259건 5클래스다 ([UEA 아카이브](https://arxiv.org/abs/1811.00075)). 중복 시계열 23개가 2024년 6월에 발견돼 제거됐다 ([Log-NCDE v3](https://arxiv.org/html/2402.18512v3)). 일반 Transformer는 이 길이에서 GPU 메모리를 초과했다 ([RFormer, NeurIPS 2024](https://arxiv.org/html/2405.20799)). 그러나 채널 간 시그니처(구간 요약 통계)로 시간축을 600배 압축해도 최고 수준을 냈다. 저자들은 시간 정보가 "자주 중복된다"고 해석했다 ([RFormer](https://arxiv.org/html/2405.20799)). seed 편차는 S6 ±16.1, Mamba ±15.8까지 간다 ([Log-NCDE v3](https://arxiv.org/html/2402.18512v3)).

**판단.** 끝 라벨 하나라 CinC와 같은 신용 할당 문제를 안는다. 편차가 커서 5분할로는 작은 효과를 가를 수 없다. 최고 점수(95.0)가 천장에 가깝다. 0단계 진단(아래)을 통과한 뒤에만 쓴다. 64샘플 패치로 281토큰이면 CinC와 비슷한 규모라 비용 부담은 작다.

### 4–6위와 제외한 과제

**확인.** 수면 단계는 맥락 효과가 가장 잘 측정된 과제다. 하지만 이득이 1 → 15에폭 구간에 몰려 있고 10 → 200에폭은 유의한 차이가 없다 ([Wang & Strodthoff 2024](https://arxiv.org/pdf/2402.17779)). SHHS에서 SleepTransformer는 21 → 200에폭에서 오히려 87.7 → 86.3%로 나빠졌다 ([L-SeqSleepNet](https://arxiv.org/pdf/2301.03441)). 2026년 프리프린트는 학습하지 않은 무작위 Transformer만으로도 수면 채점이 좋아진다고 보고했다(초록만 확인) ([Liu 외](https://arxiv.org/abs/2605.09905)). psMNIST에서 Spike-driven Transformer는 이미 96.21%다(PMSN 보고) ([PMSN](https://arxiv.org/abs/2408.14917)).

**판단.** Sleep-EDF는 "평활 함정 검사"용으로만 쓸 만하다. psMNIST·순차 CIFAR는 생체 신호가 아니다. 대신 어텐션 없이 신피질 단독의 기억 길이를 문헌 수치와 맞춰 보는 보정용으로 쓸 수 있다. Apnea-ECG는 ECG 파이프라인을 그대로 쓰지만 시험 기록이 35건이다. CPSC 2021은 과제 정의상 기록 전체를 봐야 하지만, 시험셋이 비공개라 환자 단위 분할과 채점 구현을 직접 해야 한다.

**제외 (확인한 이유).** 원시 Speech Commands는 스파이킹 LMUFormer가 프레임의 68%(87/128)만으로 정확도의 99%를 냈다 ([LMUFormer, ICLR 2024](https://arxiv.org/abs/2402.04882)). 기억 과제라기보다 스트리밍 효율 과제다. 데이터도 한 epoch에 약 3.9억 샘플이다(판단: 학습 24,482개 × 16,000, [S5](https://arxiv.org/html/2208.04933)). LRA는 커널 61짜리 합성곱으로 거의 최고 성능이 나오고 Text는 커널 5로 충분하다. Pathfinder만 예외다 ([Miralles-González 외](https://arxiv.org/html/2501.14850v1)). 발작 검출은 TUSZ에서 60초 클립이 12초보다 대개 나빴고 ([Tang 외](https://arxiv.org/pdf/2104.08336)), 보류 데이터 최고 이벤트 F1이 32%다 ([SzCORE, PMLR 2026](https://proceedings.mlr.press/v306/dan26a.html)). Icentia11k 전체는 1.1 TB이고, 끝까지 미세조정하면 16초 → 10분 맥락의 이득이 AUPRC 0.946 → 0.960으로 작다(AUC는 0.995 → 0.989로 오히려 낮음) ([Sameh 외](https://arxiv.org/pdf/2608.12695)). CAPTURE-24는 사후 HMM만으로 κ가 0.704 → 0.814로 오르고 3,883시간짜리다 ([Chan 외](https://arxiv.org/pdf/2402.19229)). UEA의 나머지 다섯 개 중 셋은 다음 절의 "시간 축이 아님·정보 없음" 함정에 걸린다.

## 0단계: 모델을 비교하기 전에 과제가 기억과 순서를 요구하는지 판정한다

**확인 (방법의 출처).** DLinear 논문은 입력 전체 섞기와 앞뒤 절반 맞바꾸기로 순서 의존성을 쟀다. ETTh1에서 Linear 예측기의 MSE는 전체 섞기로 81.06%, 반 맞바꾸기로 4.78% 나빠졌다. Informer는 각각 1.98%, 0.18%였다 ([Zeng 외](https://arxiv.org/pdf/2205.13504)). 전체 섞기는 크게 해치지만 반 맞바꾸기는 거의 무해하다는 것은 의존성이 절반 블록 안의 국소 순서에 있다는 신호다. 다만 이 섞기가 평가 때만 적용됐는지는 본문에 명확하지 않다. Khandelwal 외는 LSTM 언어모델이 약 200토큰의 맥락을 쓰지만 50토큰보다 먼 맥락에서는 단어 순서를 무시한다고 보였다 ([Khandelwal 외](https://arxiv.org/abs/1805.04623)). "먼 맥락을 쓴다"와 "먼 맥락의 순서를 쓴다"를 따로 재야 한다는 뜻이다. 스파이킹 쪽에서는 평가 시 시간 뒤집기·지터 교란이 쓰였다 ([Yu 외](https://arxiv.org/html/2507.16043)).

**판단 (등록할 진단).** 아래 다섯 진단을 모든 후보 과제에 모델 비교보다 먼저 적용한다. 판정 문턱은 우리가 정한 값이다. 문헌에 근거가 있는 문턱은 찾지 못했다.

| 진단 | 방법 | 사전 판정 규칙 (판단) |
|---|---|---|
| D1 잘라내기 | 마지막 k, 처음 k, 먼 구간 k 토큰만 남김. k = 1, 2, 4, …, N. 기준 모델(Spikformer식)과 하한(`mix_none`) 모두 | 포화 지점 k*를 보고한다. 하한이 전체 이득의 절반 이상을 얻으면 "증거 누적형" 과제로 기록한다 |
| D2 평가 시 섞기 | 원본으로 학습하고 평가 때만 전체 섞기, 블록 섞기(b = 1, 2, 4, 8, 16), 반 맞바꾸기, 시간 뒤집기 | 모델이 순서를 쓰는지 보고한다(과제 판정에는 안 씀) |
| D3 섞기 재학습 | 표본마다 새 무작위 순서로 섞은 데이터로 처음부터 학습, seed 3. 고정 순열은 쓰지 않는다(psMNIST처럼 학습 가능해지기 때문) | 원본 − 재학습 ≥ max(2점, seed 표준편차의 2배)이면 "순서 필요", 아니면 "순서 무관" |
| D4 평활 대조 | 토큰별 단독 모델 + HMM 또는 중앙값 평활(토큰 라벨 과제만) | 맥락 모델이 이 대조를 못 넘으면 "평활형" 과제로 기록한다 |
| D5 도달 거리 대비 | 기존 `rhythm_analysis.py`로 신피질 도달 거리를 잰다 | k*가 도달 거리보다 짧으면 "상태가 나를 몫이 없음"으로 기록한다 |

D2와 D3는 서로 다른 것을 잰다. D2는 "이 모델이 순서를 쓰는가", D3는 "이 과제가 순서를 요구하는가"다. 둘 다 필요하다.

**판단 (CinC 소급).** D1·D2는 저장된 가중치로 평가만 하면 된다. D3는 한 조건 × seed 3이다. 비용이 작고, 앞선 무효 결과의 원인을 기록으로 확정한다. 우리 예측은 D3에서 "순서 무관"이거나 차이가 작게 나오는 것이다. 그렇게 나오면 "CinC는 기억이 필요 없는 증거 누적형 과제였다"로 정리하고 CinC를 기억 주장에서 뺀다.

## 사전 등록 설계 1: 지연 단서 ECG에서 어텐션을 가린다

**목적 (판단).** "T = N 상태가 어텐션이 볼 수 없는 정보를 나른다"를 직접 시험한다. 이 설계의 요소는 Ni 외(기억·신용 할당 분리), DH-SNN(지연 XOR), DelayNet(단서 누적), Griffin(창 밖 붕괴)의 방법을 조합한 것이다. 문헌에 그대로 있는 프로토콜은 아니다.

**과제 구성 (판단).**

| 요소 | 설정 |
|---|---|
| 배경 신호 | CinC 2017 학습 fold의 실제 ECG. 125 Hz, 64샘플 패치, 간격 32 → 117토큰(토큰당 0.256초). 리듬 라벨은 버린다 |
| 단서 1 | 무작위 위치 t1에 1토큰 폭의 합성 파형 A 또는 B(1비트). 진폭은 주변 ECG의 RMS에 맞춘다 |
| 단서 2 (질의) | t2 = t1 + Δ에 같은 방식의 1비트 |
| 라벨 | XOR(단서 1, 단서 2). 우연 수준 50%. 리듬 라벨과 독립 |
| 지연 Δ | 4, 8, 16, 32, 64, 96토큰(1.0–24.6초). 길이 N은 117로 고정해 Δ와 함께 변하지 않게 한다. 학습은 Δ를 섞고, 평가는 Δ별로 한다 |
| 읽기 | t2 토큰의 출력만 쓴다. 토큰 평균 풀링은 금지한다. 평균 풀링은 그 자체로 전 구간을 섞는 통로다 |
| 방해 입력 | 단서 사이의 실제 ECG. 선택 사항으로 무시해야 할 제3 파형 C를 섞는다 |
| 조밀 판 | t1 뒤 8토큰마다 질의를 두고 각 질의에서 XOR(단서 1, 질의 k)을 맞힌다(DH-SNN 다중 시간척도 XOR 형식) |

**조건 (판단).**

| 조건 | 어텐션 | 목적 |
|---|---|---|
| A | 전체 인과 어텐션 | 대조. 어텐션이 모든 Δ를 본다. T = N 이득이 없을 것으로 예측 |
| B (주) | 인과 창 어텐션, W = 8토큰(약 2초) | Δ > R이면 단서 1은 상태로만 t2에 닿는다 |
| C | B와 같음. Δ ≤ 32로 학습하고 Δ = 64, 96에서 평가 | 학습 길이 밖 외삽 |
| D | B + 조밀 감독 | "기억이 필요 없음"과 "기억을 학습 못 함"을 가른다 |

수용 영역 R은 층 수 × W에 패치 임베딩 폭을 더해 계산한다. 그리고 M0(아래)에 도달 거리 측정을 돌려 R 밖에서 변화가 정확히 0인지 확인한다.

**모델 (판단).** 신피질을 붙이는 방식(B 실험의 키·값 덧붙임 또는 Neo-mixer)은 실행 전에 하나로 고정한다. 신피질은 순방향(인과)만 쓴다.

| 이름 | 구성 | 역할 |
|---|---|---|
| M0 | 창 어텐션 Spikformer식, 신피질 없음 | 기준. Δ > R에서 우연이어야 한다 |
| M1 | M0 + T = N 신피질. LIF, f-LIF, population LIF, population f-LIF (soma 없는 변형 포함 여부는 10-22 결정을 따름) | 시험 대상 |
| M2 | M0 + 기억 없는 신피질. 네 뉴런 각각 | 같은 뉴런·같은 파라미터의 주 대조 |
| M3 | 비스파이킹 GRU | 양성 대조: 순환 상태로 풀리는 과제인가 |
| M4 | 전체 어텐션 Spikformer식 | 양성 대조: 단서를 검출하고 XOR를 배울 수 있는가 |

**타당성 관문 (모두 통과해야 주 판정을 읽는다).**

| 관문 | 기준 (판단) | 실패하면 |
|---|---|---|
| G1 | M4 정확도 ≥ 90%, 모든 Δ | 단서 파형 설계를 고친다 |
| G2 | M3 정확도 ≥ 90%, 해당 조건의 최대 Δ | Δ 범위를 줄인다 |
| G3 | M0 정확도 ≤ 55%, Δ > R | 누수. 중단한다 |
| G4 | M2 정확도 ≤ 55%, Δ > R | 누수. 중단한다 |
| G5 | 모든 run이 존재하고 값이 유한함 | "판정 불가". 결측을 "차이 없음"으로 읽지 않는다 |

**판정 규칙 (판단).** 주 결과 E1은 뉴런별로 조건 B, Δ > R 구간의 평균 정확도 차이 M1 − M2(같은 뉴런)다. seed는 5개다. 평균 ≥ +10점이고 5/5 seed가 양수면 "좋음", 평균 ≤ −10점이고 5/5가 음수면 "나쁨", 그 밖은 "차이 없음"이다. 주 뉴런은 population 계열이다. 도달 거리가 길다고 측정된 것은 population f-LIF뿐이므로, population LIF는 실행 전에 같은 도달 거리 측정을 먼저 하고 주 뉴런을 고정한다. LIF는 미리 예측한 음성 대조다. 문턱 10점은 이진 과제에서 문헌의 효과가 컸다는 점(LIF 0.504 vs TS-LIF 0.977, [TS-LIF](https://arxiv.org/abs/2503.05108))을 보고 보수적으로 잡은 값이다. 부 결과는 다섯 가지다. E2는 기억 지평 Δ50(정확도가 75%로 떨어지는 Δ)을 도달 거리·τ와 비교한다. E3는 조건 A의 M1 − M2다. E4는 조건 D − B의 차이, E5는 조건 C의 외삽 정확도, E6은 아래 개입 결과다.

**인과 개입 (같은 학습 가중치로 추론 때만).**

| 개입 | 방법 | "정보가 상태에 있다" 판정 (판단) |
|---|---|---|
| 추론 시 리셋 | t1 + 1에서 신피질 상태를 0으로 | Δ > R 정확도가 55% 이하로 떨어짐 |
| 상태 바꿔 끼우기 | 단서 1만 다른 두 표본 사이에서 t1 + 1 이후 신피질 상태를 교환 | 예측의 80% 이상이 기증 표본의 단서 1을 따름 |
| 신피질 입력만 섞기 | 어텐션 입력은 그대로 두고 T = N 경로의 입력 순서만 섞음 | 정확도 하락을 보고 |
| 선형 해독 | 막전위에서 단서 1을 지연 d별로 해독 | 곡선을 보고. 기억 용량 수치 계산의 함정에 주의 ([Ballarin 외, JMLR 2024](https://arxiv.org/abs/2305.01457)) |

추론 시 리셋·상태 바꿔 끼우기 같은 인과 개입을 실제 과제에 적용한 스파이킹 논문은 찾지 못했다. 이 부분이 문헌보다 한 단계 직접적인 증거가 된다.

**결과 읽는 법 (판단).**

| 조건 A | 조건 B (Δ > R) | 개입 | 해석 |
|---|---|---|---|
| 이득 없음 | 이득 있음 | 효과 있음 | 상태가 어텐션이 못 보는 정보를 나른다. 주장 성립 |
| 이득 없음 | 이득 없음, D에서만 이득 | — | 학습(신용 할당) 문제다. 끝 라벨 과제에서 상태를 쓰려면 학습 신호를 보강해야 한다 |
| 이득 없음 | D에서도 이득 없음 | — | 그 뉴런의 상태는 R보다 먼 거리를 나르지 못한다. Δ50과 도달 거리를 비교한다 |
| — | 이득 있음 | 효과 없음 | 이득이 상태 정보가 아닌 다른 경로에서 온다. 누수 점검을 다시 한다 |

**사전 예측 (판단).** 조건 A에서는 모든 뉴런이 "차이 없음"이다. LIF의 Δ50은 16토큰 이하다. 근거는 도달 거리(d = 10에서 1.65%)와 TS-LIF 표(LIF 20스텝에서 우연)다. population 계열은 Δ50이 64토큰 이상이다. 근거는 population f-LIF에서 d = 50에 3.4–4.9%가 남는 도달 거리다(population LIF는 미측정).

**실행 규모 (판단).** CinC B 실험의 run당 시간(30 epoch)은 기억 없는 대조 461–477초, LIF 2,094–2,326초, population LIF 4,554–4,681초, population f-LIF 4,876–5,060초였다 ([MODI 10-27](../docs/MODI_PROJECT_LOG.md)). 같은 117토큰·비슷한 표본 수라면 run당 0.1–1.4시간이다. 조건 4 × 모델 11 × seed 5 = 220 run이다. GPU당 1개로 돌리면 대략 1–3일이다. 먼저 A·B만(110 run) 돌리고, C·D는 LIF와 population LIF로 줄일 수 있다.

## 사전 등록 설계 2: PPG-DaLiA 스트리밍 심박에서 평활과 겨룬다

**목적 (판단).** 실제 생체 신호에서 T = N 상태가 평활과 어텐션 이상의 시간 정보를 주는지 본다. 이 과제로는 "긴 기억"이 아니라 "추적"까지만 주장한다는 점을 등록 문서에 미리 적는다.

**프로토콜.**

| 요소 | 설정 |
|---|---|
| 데이터·분할 (확인) | Log-NCDE 코드 그대로. 15명, 6채널, 개인별 70:15:15 연속 구간, 같은 시드 ([Log-NCDE](https://arxiv.org/html/2402.18512v3); [process_ppg.py](https://github.com/Benjamin-Walker/log-neural-cdes/blob/main/data_dir/process_ppg.py)) |
| 창 (확인) | 49,920샘플, 간격 4,992. 창당 심박 라벨 390개(2초마다) |
| 지표 (확인) | 정규화 단위의 MSE×10⁻², 같은 분할 5회 평균. BPM으로 환산해 다른 프로토콜과 비교하지 않는다 |
| 토큰 (판단) | 128샘플 = 2초 = 토큰 하나 → 390토큰, 토큰마다 출력 하나 |
| 학습 (판단) | 검증 MSE 조기 종료. 모든 모델에 같은 학습률 탐색 |

**조건 (판단).**

| 조건 | 어텐션 | 목적 |
|---|---|---|
| S1 | 토큰별(W = 1, 맥락 없음) | 평활 대조의 바탕 |
| S2 (주) | 인과 창 W = 4토큰(8초 = 라벨 창 길이) | 상태가 창 밖 과거를 나르는가 |
| S3 | 인과 창 W = 16토큰 | 창 크기에 따른 변화 |
| S4 | 전체 인과 | 스트리밍 상한 |
| S5 | 전체 양방향(문헌 프로토콜) | 문헌 기준값과 비교(보고만) |

**모델 (판단).** M0(창 어텐션), M1(T = N 신피질, 네 뉴런), M2(기억 없는 신피질, 최소 LIF와 population LIF), M5(S1 출력 + HMM/Viterbi 평활), M6(S1 출력 + 중앙값 필터), 비스파이킹 GRU를 둔다. M5와 M6은 추가 학습이 없다.

**진단 (모델 비교 전, 판단).** D1은 M0의 W = 1, 2, 4, 8, 16, 64, 390으로 인과 잘라내기 곡선을 그리고 포화 지점 k*를 찾는다. **k* ≤ 4(8초)이면 긴 맥락 주장은 불가능하고, 상태의 역할은 추적·평활로 한정한다**고 미리 적는다. D3는 창 안의 토큰 순서를 표본마다 섞어 재학습한다. D4는 M5·M6이다.

**판정 규칙 (판단).** 주 결과는 조건 S2에서 두 조건을 모두 만족하는가다. 첫째, M1의 MSE가 같은 뉴런의 M2보다 상대적으로 10% 이상 낮고 5/5 run에서 같은 방향이다. 둘째, M1의 MSE가 평활 대조 M5보다 5/5 run에서 낮다. 문턱 10%는 문헌 편차(LinOSS-IM ±0.23/6.4, PMSN ±0.53/5.17)의 1–2.5배 정도로 잡은 값이다. 결측·NaN이 있으면 "판정 불가"다.

| M1 vs M2 (S2) | M1 vs 평활 대조 M5 | 해석 (판단) |
|---|---|---|
| 좋음 | 좋음 | 상태가 평활 이상의 시간 정보를 나른다(추적) |
| 좋음 | 같거나 나쁨 | 상태의 효과는 평활이다. "기억" 주장 불가 |
| 차이 없음 | — | 이 과제에서 상태 기여 없음 |

**한계 (판단).** 코드가 개인별 전체 기록으로 최소·최대 정규화를 하므로 시험 구간의 크기 정보가 학습에 조금 섞인다. 기준값과 비교하려면 그대로 두고 한계로 적는다. 5회 반복은 한 분할 위의 반복이라 사람 사이 편차를 재지 못한다. 필요하면 BeliefPPG식 LoSo를 별도 보고로만 붙인다.

**실행 규모 (판단).** 학습 창은 개인당 약 71개, 모두 약 1,070개로 추정된다(조사 노트의 코드 기반 추정, 보고된 수치 아님). 128샘플 토큰이면 epoch당 약 42만 토큰-스텝으로 CinC와 같은 자릿수다. 원시 T = N(49,920스텝)은 SSM조차 batch 4와 A100이 필요했으므로 패치가 필수다. S2–S4에 M0·M1(4)·M2(2)를 돌리고 S1·S5를 더하면 약 120–150 run이다.

## ETT·MIT-BIH 결과가 바꿀 수 있는 것은 우선순위뿐이다

**확인 (우리 기록).** 일반화 묶음은 막전위 차이 Neo-mixer LIF와 Spikformer식을 비교한다. Neo-mixer LIF는 어텐션 없이 순방향·역방향 T = N 스택으로 토큰을 섞는다. ETT는 과거 96스텝을 패치 8·간격 4로 잘라 24토큰이고, MIT-BIH는 심박 187샘플을 패치 32·간격 16으로 잘라 11토큰이다. 규모는 ETT 4종 × 예측 길이 96–720 × 9조건 × seed 3 = 432 run, MIT-BIH 27 run이다 ([MODI 기록 10-27 17:32](../docs/MODI_PROJECT_LOG.md)). 외부 문헌에서 ETTh1은 입력 전체 섞기에 민감하고 반 맞바꾸기에는 둔감했다 ([Zeng 외](https://arxiv.org/pdf/2205.13504)). SHD에서는 population f-LIF가 LIF보다 5.8–6.0점 좋았다(5/5 seed) ([MODI 기록 10-20 16:18](../docs/MODI_PROJECT_LOG.md)).

**판단.** 두 과제는 24토큰·11토큰이다. LIF 도달 거리(약 10토큰)와 비슷하거나 짧고, 어텐션이 전부를 본다. 그래서 어떤 결과가 나와도 "T = N 상태가 어텐션이 못 보는 정보를 나른다"를 지지하거나 반박하지 못한다. ETT에서 이기면 "국소 순서를 쓰는 짧은 과제에서 T = N 섞기가 통한다"까지다. 바뀌는 것은 실행 순서와 대조군 구성이다.

| ETT 결과 | MIT-BIH 결과 | 읽는 법 (판단) | 권고 변화 (판단) |
|---|---|---|---|
| 같거나 좋음 | 같거나 좋음 | 어텐션 없는 T = N 섞기가 짧은 과제에서 범용 섞기로 통한다 | 순위 유지. PPG-DaLiA를 앞당긴다. Forecaster의 창 정규화·채널 독립·토큰별 출력 구조를 재사용한다 |
| 같거나 좋음 | 나쁨 | 국소 순서는 쓰지만 단일 박동의 국소 특징에서 손해 | 설계 1·2에 "Spikformer식 + 기억 없는 신피질"을 넣어 국소 비용을 따로 잰다 |
| 나쁨 | 같거나 좋음 | 순서가 중요한 짧은 예측에서 T = N 섞기가 약하다 | PPG를 보류한다. 설계 1을 신피질 단독(어텐션 없음) 판부터 돌려 기억 지평을 먼저 잰다 |
| 나쁨 | 나쁨 | CinC 동률이 CinC에만 해당할 수 있다 | 설계 1만 진행한다. 주장 범위를 "어텐션이 못 보는 조건"으로 좁힌다 |

뉴런 축도 함께 본다(판단). ETT에서 population 계열이 LIF보다 좋으면, SHD에 이어 두 번째 사례가 된다. 그러면 설계 1·2의 주 뉴런을 population LIF/f-LIF로 확정한다. 차이가 없으면 짧은 과제라 예상된 결과이므로 바꿀 것이 없다. 같은 날 사전 고정한 B 90 epoch 재실험(10-27 17:06 항목)도 같은 식으로 읽는다. T = N LIF − 기억 없는 대조가 90 epoch에서 양수로 바뀌면 30 epoch 무효 결과의 일부는 학습 부족이었다. 그 경우 설계 1·2의 "수렴까지 학습" 규칙이 더 중요해진다. 바뀌지 않으면 "어텐션이 다 본다"는 설명이 그대로 선다.

## 결론

CinC의 무효 결과는 T = N 기억 일반에 대한 반증이 아니다. 전체 어텐션, 10토큰 안에서 사라지는 LIF 상태, 증거 누적으로 풀리는 과제가 겹치면 문헌과 우리 측정 모두 "기여 없음"을 예측한다. 그래서 연구 질문을 바꿔야 한다(판단). "T = N 상태가 어텐션에 정보를 더하는가"는 어텐션이 다 볼 때는 정보 면에서 더할 몫이 없다. 남는 것은 학습 편의 같은 귀납 편향뿐이다. 시험 가능한 질문은 이것이다. **"어텐션이 제한될 때(창, 스트리밍) T = N 상태가 R보다 먼 거리로 몇 비트를 나르는가, 그리고 그 에너지는 얼마인가."** 토큰마다 한 스텝, 일정한 메모리라는 SNN의 장점이 자연스럽게 드러나는 조건도 바로 여기다.

이 방향에는 빈자리가 있다. 어텐션 창을 통제하면서 순환 뉴런 상태의 기여를 지연-정확도 곡선으로 잰 스파이킹 연구, 실제 과제에서 추론 시 리셋·상태 바꿔 끼우기를 한 스파이킹 연구, UEA·PPG에서 T = N 순환 경로를 스파이킹 자기 주의와 비교한 연구를 모두 찾지 못했다. 관문을 통과한 상태로 나온 음성 결과도 "막전위 기억이 어디서 멈추는가"에 대한 구체적 증거가 된다. 우리 예측은 분명하다(판단). LIF는 16토큰 너머에서 실패하고, population 계열이 유일한 후보다. population이 설계 1은 통과하고 설계 2에서 평활을 못 넘으면, 결론은 "막전위 기억은 작동하지만 이 실제 과제는 그것을 요구하지 않는다"가 된다. CinC식 무효 결과를 하나 더 쌓는 것보다 훨씬 정확한 결론이다.
