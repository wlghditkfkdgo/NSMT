## 1. 주 모델 v3-A — 공유 소마(shared-soma) population f-LIF

### 1.1 설계 의도

하나의 **논리 뉴런 = 하나의 population**이다. Population은 **같은 입력 전류 `I_n`을 받고 하나의 스파이크 `s_n`을 낸다.** 내부의 K개 구성원은 서로 다른 시간척도로 같은 입력을 적분하며, **기억과 검색 key를 담당**할 뿐 각자 발화하지 않는다. 발화와 reset은 소마 한 곳에서만 일어난다. (사용자 요구)

이 구조는 DH-SNN(Zheng et al., Nat. Commun. 2024)의 핵심 성질 — *기억을 담는 가지는 절대 리셋하지 않고 소마만 발화·리셋* — 과 같은 계열이며, 개념 문서 §13.2의 "단일 논리 스파이크"에 해당한다.

### 1.2 기호

| 기호 | 의미 |
|---|---|
| `n` | 현재 patch 시점, 0..T−1 (T=42) |
| `j` | 과거 patch 시점, `j<n` |
| `k` | 구성원(가지) 색인, 1..K (K=4) |
| `I_n ∈ R` | population이 공유하는 입력 전류 |
| `u_{n,k}` | 가지 k의 상태(리셋 없음) |
| `f_{n,k}` | 가지 k의 dynamics 값 = 기억 항목 |
| `v_n` | 소마 막전위 |
| `s_n ∈ {0,1}` | population의 유일한 출력 스파이크 |
| `ρ_{n,j,k}` | 과거 사건 j를 현재 n에서 얼마나 읽을지 |

### 1.3 수식

**(a) 가지 — 기억과 key. 리셋 없음.**

```
f_{n,k} = ( I_n − u_{n,k} ) / τ_k                        τ = [2, 4, 8, 16]
u_{n+1,k} = Σ_{j≤n}  b_{n−j}^{(α)} · ρ_{n,j,k} · f_{j,k}        (ρ_{n,n,k} = 1)
b_d^{(α)} = [ (d+1)^α − d^α ] / Γ(α+1)                   h=1, 1/τ 규약
```

**(b) 선택 — 공유 내용 점수 × 가지별 lag 사전분포.**

```
ξ_n = [ u_{n,1..K} ; I_n ] ∈ R^{K+1}
e_{n,j} = − ‖ W_Q ξ_n − W_K ξ_j ‖² / (d_q · ϑ)            ϑ = 온도
p_n = sparsemax(e_n)  또는  softmax(e_n)                   (sparse / dense 모드)
B_n = Σ_{j<n} b_{n−j}
ρ̃_{n,j} = B_n · p_{n,j} / Σ_{ℓ<n} b_{n−ℓ} p_{n,ℓ}         (커널 총질량 보존)
ρ_{n,j,k} = [ (1−η) + η · ρ̃_{n,j} ] · π_k(n−j)            η ∈ [0,1]
```

**(c) 소마 — 발화와 reset.**

```
a_n = Σ_k w_k u_{n,k}
v_n = v_{n−1} + ( a_n − v_{n−1} ) / τ_s − θ · s_{n−1}
s_n = H( v_n − θ )                                        backward는 pinned arctan 식
```

**(d) 출력과 층 연결.** 층 출력은 `s_n` 하나(`[T, B·C, D]`). 다음 층 전류는 `I^{(l+1)}_n = scale · Linear(s^{(l)}_n)`.

### 1.4 환원(reduction)과 수치 검증

| 조건 | 환원 결과 | 검증 |
|---|---|---|
| `η=0, π≡1` | 선택 없는 full-history fractional population | 정의상 |
| `α=1, η=0` | 가지 = 보통 leaky integrator `u ← u + (I−u)/τ`, 전체 = 다중시간척도 선형필터 + LIF 소마 | **측정: 최대오차 0.0** (`prereg_numerics.txt` B1) |
| `K=1` | scalar f-LIF + 소마 | 정의상 |
| `α=1, K>1, η=0` | **fractional 커널의 sum-of-exponentials 근사**와 동등한 형태 → 주 기준선 | LongSpike의 SOE 논거 |

### 1.5 v3-A가 자동으로 없애는 문제

1. **reset–선택 교란 소멸.** 기억 항목 `f_{j,k}`에 reset 항이 없다. 선택 `ρ`는 순수하게 subthreshold 증거만 조절한다. (EN 계획 §14.5, 재검토안 §2.2의 핵심 난점이 구조적으로 제거됨)
2. **"발화 판정량 ≠ 상태" 문제 소멸.** 가지 상태는 리셋되지 않는 연속량이고, 발화는 소마 변수 `v`가 결정한다. 두 양이 같아야 한다는 요구 자체가 사라진다.
3. **성분별 출력 붕괴 논쟁 유보.** 출력이 하나이므로 개념 문서 §13의 미결 항목을 1차 실험에서 우회한다.

### 1.6 v3-A에서 "population 내부 상호작용"의 위치

확산 결합(`−λL u`)은 제거한다. 대신 상호작용은 두 경로로 존재한다.

- **공유 선택:** `ρ_{n,j}`가 population 전체 상태 `ξ_n`으로 계산되므로 `∂u_{n+1,k}/∂u_{n,ℓ} ≠ 0 (ℓ≠k)`이다. 즉 **다른 구성원의 상태가 내 구성원의 다음 상태를 바꾼다.** full 모드(η=0)에서만 0이 된다.
- **소마 혼합:** `w_k`가 K개 시간척도를 하나의 발화 결정으로 합친다.

따라서 "상호작용 제거"가 아니라 **"확산 결합이라는 특정 형태를 제거하고, 선택과 소마를 상호작용 경로로 삼는다"**가 정확한 서술이다.

### 1.7 보류: v3-B (성분별 스파이크)

v3-A의 성능과 진단이 확보된 뒤에 비교한다. v3-B는 각 구성원이 자기 스파이크를 내고 reset을 가지므로 §1.5의 세 문제가 다시 살아난다. 그때는 reset 규약(D1의 네 후보)을 명시적으로 비교해야 한다.

## 2. 사전등록 결정

### D1. Reset·발화 규약 — v3-A는 소마 subtractive reset, 가지는 리셋 없음

- **결정:** 주 모델은 §1.3(c). 가지 이력에는 reset 항이 들어가지 않는다.
- **원본 대조군(Phase A에서만):** ① spikeDE 고정 커밋 경로(발화는 `U_n+D_n`, reset은 `−θS_n/τ`가 커널로 전파), ② 논문 식 (13) 문자 그대로, ③ 재검토안의 hybrid(`−Σ θ S_r` 별도 보존), ④ **L1/Teka 형식**(상태 점프 + 점프 증분이 memory trace에 멱함수 가중으로 반영). 네 경로의 궤적 차이를 기록한다.
- **근거:** 재검토안 §2.2가 보인 α=1 반례(식 (13)을 문자 그대로 재합산하면 `V_2=2.3`, 보통 Euler reset LIF는 `V_2=1.3`)는 "post-reset 상태를 저장한다"만으로 규약이 정해지지 않음을 보여준다. v3-A는 이 분기 자체를 피한다.
- **L1/Teka 후보의 하위 결정(측정 근거 있음):** 리셋으로 생긴 전압 점프(음의 증분)를 memory trace에 **넣을지 뺄지**를 반드시 선언해야 한다. 동일 조건(τ=4, α=0.6, I=1.6, θ=1, refractory=1, 200 step)에서 넣으면 스파이크 25개(ISI 9,9,8,8…), 빼면 5개(ISI 27→59)로 **질적으로 다른 뉴런**이 된다. 또 L1 가중치는 목표 시점 N 기준 `(N−k)^{1−α} − (N−1−k)^{1−α}`이며, 한 칸 어긋난 인덱싱은 **α=1 검사(모든 가중치 0)를 통과하면서** α<1에서 진동을 만든다. Phase A 필수 검사 항목.
- **변경 조건:** v3-B로 넘어갈 때 네 후보를 다시 판정한다.

### D2. 선택 단위 — 공유 내용 점수 × 가지별 lag 사전분포(하이브리드)

- **결정:** `ρ_{n,j,k} = [(1−η)+η ρ̃_{n,j}] · π_k(n−j)`. 내용(어느 사건인가)은 population이 공동 결정, 사용 강도(얼마나 쓸까)는 가지의 시간척도에 따라 다름.
- **비교군:** (2) 순수 공유 `π_k≡1`, (1b) 가지별 Q_k/K_k를 둔 multi-head 선택.
- **기각:** (1a) 가지가 자기 스칼라 이력만 보는 방식 — 개념 문서 §6.3의 aliasing 문제로 되돌아감.
- **`π_k` 사양:** `π_k(d) = exp(−d / (c·τ_k))`, c는 population 공통 스칼라 하나만 학습(초기 c=∞ ⇒ `π≡1`, 즉 중립극한 포함).
- **판정 지표:** synthetic에서 정답 사건 질량, 가지별 선호 lag, (1b)의 head 간 선택 불일치율(키메라 비율).

### D3. 결합 — 확산 결합 제거

- **결정:** `λ = 0`. `−λ L u` 항을 주 모델에서 뺀다.
- **근거:** 확산은 이질성을 줄이는 방향이고(계획서 §6.3도 인정), 문헌에서 gap junction은 이질성을 보상·동기화하는 기제로 보고된다. 상호작용 요구는 §1.6의 두 경로가 충족한다.
- **보류 실험:** 필요하면 비확산형(비대칭/2차 결합, TS-LIF·adLIF 계열)을 별도 가설과 함께 소거 실험으로. 이때 `A1 ≠ 0`이면 동질 population 불변성이 깨지므로 비교군을 다시 구성해야 한다(재검토안 §2.4).

### D4. ρ 스케일 — 질량보존형 + 볼록 결합

- **결정:** `ρ = (1−η) + η ρ̃`, `ρ̃ = B_n p / Σ b p`.
- **성질:** `η=0`이면 정확히 f-LIF(중립극한). `Σ_j b_{n−j} ρ_{n,j} = B_n`이 **항상** 성립(측정: κ=1.000). 점수가 균일하면 `ρ≡1`. sparsemax의 정확한 0은 `(1−η)`로 바닥이 깔린다 — **완전 배제를 원하면 `η=1`로 두거나 별도 hard-mask 모드를 선언**해야 한다.
- **기각:** `ρ=p/max p`(감쇠 전용, 측정 κ=0.486 — 올바르게 골라도 커널 질량이 절반으로 줄어 선택과 감쇠가 엉킴), `ρ=n p`(측정 κ=0.973으로 질량 보존이 아님).
- **상한:** `ρ_max`를 둘 경우 정확한 sparse support·상한·질량보존을 동시에 만족할 수 없다(재검토안 §2.3). 우선순위는 **질량보존 > 상한**으로 고정하고, `ρ`의 실제 최댓값을 진단으로 기록한다.
- **필수 대조:** 질량 맞춤 균일 개입 `ρ ≡ κ_n`(EN 계획 §14.4)을 **학습된 조건으로도** 포함한다.

### D5. 선택자 초기화 — 중립극한에서 출발

- **결정:** 학습 시작 시 `η=0`(또는 온도를 충분히 크게)으로 두어 **f-LIF에서 출발**하고, 선택은 학습으로 획득하게 한다. `W_Q=W_K=[I 0]`.
- **근거:** 온도 0.25·항등 초기화에서는 상태 차이가 O(1)이라 sparsemax가 처음부터 희소해져 "Full vs Sparse" 비교가 초기화에 오염된다.
- **기록:** epoch별 `η`(학습 시), 초기/최종 `κ_n`, support 크기.

### D6. 기준선 — α=1 이질 population을 주 기준선으로

- **주 기준선:** `hetero α=1, η=0` (= SOE 근사 / DH-SNN 계열). τ 범위는 window에 맞춰 `[2,4,8,16,32,64]`까지 확장한 변형도 포함.
- **추가 기준선:** scalar f-LIF(K=1), conventional LIF(β=e^{−1/τ}, subtractive reset), 동일 split·scaler의 ridge 선형, window-mean, persistence.
- **근거:** LongSpike가 보인 항등식 — 멱함수 커널은 지수함수 혼합이고 **M=2개 지수만으로도** LRA-Text 80.4%→88.2%를 얻었다. 우리의 K=4 이질 population(α=1)은 그 자체로 4항 SOE다. 이 기준선을 못 이기면 fractional 차수는 논문에서 빠져야 한다.

### D7. α 격자와 T

- **결정:** `α ∈ {0.3, 0.5, 0.7, 1.0}`, 기본 0.7. T=42 고정.
- **근거:** T=42·α=0.7에서 커널은 거의 평평하다(`b_41/b_1 = 0.367`, 질량의 절반이 lag 15 너머, 총질량 15.06). α의 의미는 T에 상대적이다. patch 크기 변경은 T와 모델 시간단위를 동시에 바꾸므로 별도 연구로 둔다.
- **주의:** α는 커널 모양뿐 아니라 총질량 `(Nh)^α/Γ(α+1)`도 바꾼다. α 비교 시 유한구간 이득표(§2 D11)를 함께 보고한다.

### D8. Readout — 스파이크 주, 막전위 진단

- **결정:** 주 결과는 `s_n` 스파이크 → `Linear`. 진단으로 막전위(analog) readout 변형을 같은 조건에서 1회 측정해 "기억은 있으나 readout이 못 읽는" 경우를 가린다.
- **추가:** flatten head(전 시점) 주 비교 + bottleneck head(마지막 시점)를 기전 연구로 병행. 두 head는 파라미터 수가 다르므로 **head 종류 간 차이를 기억 효과로 해석하지 않는다.**

### D9. 구조 — v3-A 주, v3-B 보류

§1.1과 §1.7. 동일 입력·동일 출력 구조를 먼저 완성하고 성능을 확인한 뒤 성분별 스파이크를 비교한다. (사용자 지시)

### D10. 실행 순서

`Phase A(수학·원본 대조) → B(population 진단·발화율 보정) → C(선택 진단) → D(synthetic recall, oracle 포함) → E(M1 ETT H96 주판정) → 확장(M3/TCN/ATT, H720 보조)`. **모델 정의가 끝나기 전에는 대규모 matrix를 실행하지 않는다.**

|---|---|---|---|
| 2 | 1/K | 2 | **0.004** |
| 2 | 1/K | 4 | 0.044 |
| 1 | 1/K | 4 | 0.120 |
| 1 | 1.0 | 1 | 0.120 |

### R3. 계수 상한 — 주 안정성 장치 (신규, D4를 보강)

```
c_{n,j} = min( b_{n−j} · ρ_{n,j} , b_0 )
u_{n+1,k} = b_0·f_{n,k} + Σ_{j<n} c_{n,j}·f_{j,k}
```

- **이유:** D4의 질량 보존은 **안정성을 보장하지 않는다.** `f_j = (I_j − u_j)/τ`는 입력과 누설을 함께 담고 있어 부호가 있으므로, 총질량을 고정해도 상쇄 구조가 바뀌면 상태가 폭주한다. 상한이 없으면 "매 스텝 직전 slot을 읽는" 정책에서 τ=2, η=0.5에 `max|u| = 397,853`, T를 늘리면 발산한다(`stability_sweep.py`).
- **중립극한 보존:** `b_d`는 `d`에 단조 감소하므로 `η=0`(⇒`ρ≡1`)에서는 `b_d ≤ b_0`이라 상한이 절대 작동하지 않는다. 상한 적용/미적용 결과가 `atol=0, rtol=0`으로 동일함을 확인했다. sparsemax의 **정확한 0도 보존**된다.
- **허용 증폭:** lag 1에서 1.60배, lag 41에서 4.37배까지. 선택 기능 자체는 살아 있다.
- **부작용:** 상한이 걸리면 `κ_n < 1`이 된다. 따라서 §3의 "`κ=1.000`" 검사는 **상한 미작동 조건에서만** 적용하고, 그 외에는 `κ`와 상한 작동률 `cap_rate`를 진단으로 기록한다(§3A G12).

### R4. 대안 (R3가 회상 과제에서 실패할 때만)

`ρ` 자체를 `[0, ρ_max]`로 clamp(`ρ_max = 3`). 채택 시 날짜부 항목으로 추가 기록한다.

### F1. 가지 시간척도 변경 — `τ = [4, 8, 16, 32]`

- **이유:** R3만으로는 가장 빠른 가지(`τ=2`)가 남는다. 최악 정책·`η=1`에서 `max|u|`가 T=42에 10.86, **T=84에 83.24**로 **길이에 따라 커진다**. `τ≥4`는 모든 η·T·정책에서 0.5503(pulse)로 유계이며 T에 거의 불변이다.
- **대안이던 τ-비례 상한은 기각:** 중립극한을 유지하려면 상한이 `b_1 = 0.687` 이상이어야 하는데(`λ ≥ 0.35`), 그 수준에서도 잡음 입력에 11.1(T=42) → 13.2(T=84)로 증가한다.
- **반응성 확인:** `τ=4`의 계단 응답(`I≡1`)은 n=1 → 0.275, n=2 → 0.371, n=4 → 0.500, n=8 → 0.638, n=42 → 0.883. 가장 빠른 가지로 충분하다.
- **연쇄 변경:** ① D11 발화율 보정값을 **재측정**한다(τ=2의 `mean|u| 0.433` → τ=4의 `0.249`). ② 동질 대조군의 `τ`는 조화평균 `K/Σ(1/τ_k)` = **8.533**(기존 4.267에서 변경). ③ §2 D11의 유한구간 이득 수치는 τ=[2,4,8,16] 기준이므로 τ=[4,8,16,32]에서 재측정해 기록한다.

### D-A. tempered 인자 제거 — `g = 0`, `π_k ≡ 1` (D2를 개정)

- D2는 "공유 내용 점수 × 가지별 lag 사전분포 `π_k(d)=exp(−dg/τ_k)`"를 채택했다. **rev.1에서 주 모델에서 제거한다.**
- **이유 셋.** ① `π`는 질량 재분배 **이후에** 곱해지므로 질량 보존을 깬다. 재계산 결과 `g=0.2`에서 `κ` = 0.93 / 0.83 / 0.67 / 0.45 (τ=4/8/16/32 대응)로 가지마다 다르게 줄어든다. ② `α=1, η=0`의 Euler 환원이 `g>0`이면 성립하지 않는다(지수 인자가 붙은 **수정** recurrence가 된다). ③ 멱함수 꼬리에 지수 절단이 걸려 "fractional 장기기억"이라는 주장 자체가 약해진다.
- **재도입 경로:** 필요하면 **별도 모델명**(tempered variant)으로, `π`를 곱한 **뒤에** 재정규화하도록 수식을 고쳐 도입한다. 그 경우 D2는 그 변형에만 적용된다.

### D-B. `η` 파라미터화 (D5를 명시화)

`η = sigmoid(η̂)`, `η̂` 초기값 0(⇒ `η=0.5`)이 아니라 **D5의 중립 출발을 유지**해 `η̂` 초기 −4(⇒ `η≈0.018`). 학습 가능. 별도로 `η=0`(full)과 `η=1`(hard) 조건을 고정값으로 실행한다. `η=1`은 안정성 최악 조건이므로 §3A G11을 반드시 켠다.

### D-D. 소마 정렬 — `a_n = Σ_k w_k · u_{n+1,k}` (§1.3(c) 개정)

- §1.3은 소마가 `u_n`을 읽는다. 그러면 시점 n의 입력 `I_n`은 `u_{n+1}`에만 들어가므로 **마지막 patch `I_{T−1}`가 출력에 전혀 도달하지 않고**, 선택도 한 스텝 늦게 반영된다.
- rev.1에서 소마는 **갱신된 상태 `u_{n+1}`**을 읽는다. 질의 `ξ_n`은 여전히 갱신 **전** 상태 `u_n`으로 만든다(인과성 유지).
- **연쇄 변경:** §4의 "회상 성적은 재등장 구간 두 번째 칸부터" 규칙을 **삭제**하고 구간 전체에서 집계한다. 첫 칸 성적은 전환 반응 속도 지표로 따로 남긴다.

### D-F. Oracle 세 종류를 구분한다 (O6를 확장)

| 이름 | 정의 | 쓰임 |
|---|---|---|
| **oracle-trained** | 정답 정책을 고정한 채 처음부터 학습 | O7 ②의 분모 |
| **test-time oracle** | 학습된 모델에 시험 때만 정답 정책 주입 | 정책 문제 vs 표현 문제 분리 |
| **generator lookup** | 생성기의 값을 그대로 출력 | 과제 하한 눈금 |

**oracle은 "이 구조의 최적"이 아니라 특권적 정책 하나다.** 학습된 정책이 oracle보다 나을 수 있으며, 그 경우도 성공으로 본다. 또 `η<1`이면 oracle이라도 실제 할당은 `M_eff = (1−η)·m₀ + η`로 구조적 상한이 걸린다(`m₀` = 정답 칸의 커널 질량 비중).

### D-H. 대조군 개정 (§4.5 개정)

| 변경 | 내용 | 이유 |
|---|---|---|
| **삭제** | `uniform` (`p` 균등) | `p` 균등 ⇒ `ρ̃ ≡ 1` ⇒ `full`과 **수학적으로 동일**. 중복 조건. 동일성 자체를 게이트로 검사(G7b) |
| **유지** | `mass_matched` (`ρ ≡ κ_n`, 내용 무관) | R3 상한 때문에 `κ < 1`이 생길 수 있어 `full`과 갈라진다. 다시 유의미 |
| **추가** | **비선형 recurrent (GRU) 기준선** | §4의 회상 과제는 "값 3개를 압축 상태에 담고 현재 신호로 꺼내기"로도 풀린다. 즉 **선택 없이도 풀릴 수 있다.** 이 과제는 "우리만 푼다"의 근거가 아니라 **"우리 구조 안에서 선택이 작동하는가"의 내부 진단**이며, 그 한계를 GRU 격차로 정량화한다 |
| **추가** | 난이도 축에 **신호 종류 수**(3 → 8 → 16) | 압축 저장으로 푸는 경로를 좁히기 위해 |

### D-J. 빠른 경로의 정의 정정 (§1.4 보강)

`η=0`에서 가지를 한 번의 행렬곱으로 계산할 때, **하삼각 계수 행렬 `B`를 입력에 그냥 곱하면 틀린다**(재계산 오차 1.21). `u`가 `f`에 되먹임되므로 유효 연산자는

```
u = H_eff · I ,   H_eff = (I_T + B·J/τ)⁻¹ · (B/τ)        (J = 하삼각 시프트 행렬)
```

이며 루프와 7.6e-16까지 일치한다. 계산 차수는 여전히 `O(T²)`이고, **속도 이득이 실제로 있는지는 두 경로를 모두 구현·측정한 뒤 보고**한다(`T=42`에서는 루프가 이미 충분히 빠를 수 있다).

### D-K. "sparse"의 층위를 분리해 보고한다

`ρ = (1−η) + η·ρ̃`이므로 **`p_j = 0`이어도 최종 계수는 `(1−η)·b_d`만큼 남는다.** 주 모델의 정확한 서술은 **"dense fractional history 위의 sparse content redistribution"**이며, 완전 배제는 `η=1`에서만 성립한다. 보고 시 `support(p)`, `support(ρ)`, `support(b·ρ)`, `support(c)`를 **각각 따로** 적는다(§3A G13).

### D-L. `K=1` 환원의 표현 정정 (§1.4 보강)

`K=1`은 "원 논문 f-LIF와 동일"이 아니라 **"scalar fractional branch + 별도 소마"**다. 가지가 리셋하지 않고 소마가 따로 있다는 점에서 원 논문의 발화·리셋 뉴런과 다르다. 결론 문장에서 이 구분을 유지한다.

### D-M. `α=1` 이질 기준선에 대한 결론 표현 (D6 보강)

K=4 이질 population(`α=1`)은 **4개의 지수 커널 합**이지 "fractional 커널의 fitted SOE 근사"가 아니다(τ 고정). 따라서 결론은 세 갈래로 나누어 쓴다.

| 만약 | 결론 |
|---|---|
| `α=1` 이질이 같거나 낫다 | **이 τ 설정·이 과제에서** fractional 차수의 기여가 확인되지 않음. 차수 폐기 여부는 τ 학습 가능화 뒤에 판단 |
| 우리가 낫고 차이가 MDE 위 | 이 조건에서 fractional 차수의 기여 확인 |
| 둘 다 `full`에 못 미친다 | 과제·보정·구조 문제. 차수 논의 이전 단계 |

## 4. Synthetic recall 프로토콜

### 4.1 왜 필요한가

v2 288회에서 ETT는 검색 메커니즘에 대해 사실상 정보를 주지 못했다(모든 검색 비교 p>0.07, 학습된 선택을 uniform으로 바꿔도 MSE 동일). **정답을 아는 과제**에서 먼저 판정한다.

### 4.2 주 과제 B — regime 재귀 회상

- 채널: regime key(M=3 one-hot + 잡음), value, 잡음 채널. 길이 L=96 step.
- regime 길이 U[6,16], 같은 key가 1–3개의 다른 regime을 사이에 두고 재등장.
- **첫 등장** 구간에만 value 채널에 `v_k ~ U[−1,1]`이 보이고, **재등장** 구간에는 0.
- 목표 `y_t` = 현재 key의 `v_k`. 재등장 구간이 회상 구간이며 보고는 이 구간 중심.
- 정답 사건 집합: 현재 key의 이전 등장 구간 시점들(생성 시 저장).
- 왜 대조군을 가르는가: "최근"은 직전 regime(오답), "uniform"은 전체 평균(오답), 고정 lag은 길이가 무작위라 불가.

### 4.3 보조 과제 A — 문맥별 lag

`c_t ∈ {A,B}`가 U[8,24] 구간 유지, `y_t = x_{t−4}`(A) 또는 `x_{t−16}`(B). 현재 scorer는 내용 유사도라 lag 자체를 표현할 수단이 없으므로 **실패해도 설계의 반증이 아니다.** 경계 확인용.

### 4.4 cue와 value를 같은 채널 경로에 두어야 하는 제약

모델은 channel-independent다. 채널 c의 population은 채널 c의 patch만 입력으로 받는다. cue를 다른 채널에 두면 그 정보가 **구조적으로 도달할 수 없어** 과제가 불가능해진다(모델의 실패가 아니라 설계 오류). 따라서 cue·value·목표는 같은 입력 스트림 안에 둔다. (EN 계획 §16.5, 재검토안 동의)

**구체적인 인코딩(사전등록).** 모델의 시간 단위는 patch이므로 **patch 하나 = 사건 하나**로 만든다. patch_size=8의 원시 위치를 `[0:M]=key one-hot, [M]=value, 나머지=0 또는 잡음`으로 채운다. 그러면 "과거 사건 j"와 "기억 slot j"와 "patch j"가 모두 같은 색인이 되어, 정답 slot 적중률을 모호함 없이 측정할 수 있다. lag도 raw step이 아니라 **patch 단위**로 정의한다(현 scorer는 내용 유사도만 보므로 raw step 단위 lag은 표현할 수단이 없다).

### 4.5 조건

| 조건 | 목적 |
|---|---|
| full (η=0) | fractional 기억만 |
| dense / sparse | 학습된 선택 |
| **oracle** | 정답 사건에 `ρ` 강제 — "고르는 게 문제인가, 쓰는 게 문제인가" 분리 |
| 학습된 uniform / recent | 사소한 정책 대조 |
| 질량 맞춤 `ρ≡κ_n` | 감쇠 대조 |
| scalar (K=1) | population 필요성 |
| capacity-matched (K·D개 독립 뉴런) | 용량 교란 |
| α=1 hetero | fractional 필요성 |

### 4.6 지표와 사전 판정 기준

- 회상 구간 MSE(oracle 대비 비율 포함), 정답 사건 질량, support hit(무작위 기대치 대비), 문맥 전환 후 선택이 옮겨가는 데 걸린 step, slot 교체 개입 ΔMSE.
- **사전 기준(예시, 실행 전 확정 필요):** 학습 sparse의 정답 사건 질량 > 0.5 **이고** MSE가 oracle의 1.5배 이내 ⇒ "검색 타당". **oracle조차 full과 차이가 없으면** 선택 설계가 아니라 사용 경로(강도·소마·readout)를 먼저 재검토.

## 5. ETT 프로토콜

- 분할: ETTh1/ETTh2 train `[0,8640)`, val `[8640,11520)`, test `[11520,14400)`. train 구간만으로 표준화. 입력 L=336, patch 8, T=42. H96 주판정, H720 보조(사후 제외하지 않음).
- window 수: H96 8209/2785/2785, H720 7585/2161/2161.
- **주 대비 2개만** 예산을 집중한다.
  - `Δ_selection = E(sparse) − E(full)`
  - `Δ_interaction = [E(coupled,sparse) − E(coupled,full)] − [E(uncoupled,sparse) − E(uncoupled,full)]` (결합 축을 되살릴 때만)
- 통계 단위: **dataset 내 seed 대응 차이**. `2 dataset × 3 seed = 6`을 동일 모집단의 독립 6쌍으로 쓰지 않는다. seed는 8–10개로 시작하되 이것이 "검정력 확보"를 뜻하지는 않는다. 사전에 검출 목표 효과(MDE)를 선언한다.
- 참고 기준선(v2에서 동일 프로토콜로 측정): ridge 선형 ETTh1 H96 .3702 / H720 .4696, ETTh2 H96 .3010 / H720 .7404; 마지막값 정규화 ridge ETTh1 .3696/.4325, ETTh2 .2719/.3925; window-mean ETTh1 .706/≈.70, ETTh2 .385/.432. **ETTh2 H720은 v2의 6개 조건 전부가 window-mean보다 나빴으므로 기전 판정에 쓰지 않는다.**

## 9. 실행 전 미결 항목과 권고 (2026-09-20 점검)

아래 9개는 **아직 확정되지 않았다.** 각 항목의 권고안을 채택하면 즉시 Phase A에 착수할 수 있다. 확정 시 이 절을 수정하지 말고 §2에 날짜가 붙은 결정으로 추가한다.

### O1. 소마 파라미터화 `(w_k, τ_s, θ, 리셋 시점)` — Phase B 차단

`w_k`가 고정 균등값이면 소마가 보는 것은 K개 시간척도의 **고정된 하나의 혼합**이라 population 다양성이 발화 단계에서 붕괴한다. 또 `τ_s=1`이면 리셋 결손이 한 스텝만 남아 발화율이 0.5에서 포화하고 입력 세기를 부호화하지 못한다.

> **권고:** `w ∈ R^{D×K}` 학습(층당 128개, 초기 1.0), `τ_s = 2` 고정, `θ = 1`, 리셋은 `−θ·s_{n−1}`(DH-SNN 형식). D11 보정표에서 이 조합은 `input_scale = 2`에서 발화율 0.138로 목표 구간에 들어온다. `τ_s = 1`과 `w` 고정은 소거 실험.

### O2. Surrogate 고정 — Phase A 차단

> **권고:** pinned 코드 식 `g(x) = (s/2) / (1 + (π/2·s·x)²)`, **s = 5.0**(`LIFNeuron`이 실제로 전달하는 값). 모든 비교 조건에 공통 적용. 함수 기본값 2.0과 논문 식 (30) `κ/(1+(κx)²)`은 별도 민감도 분석으로만.

### O3. 선택자 파라미터화 `(η, π_k, ϑ, W_Q/W_K 공유 범위)` — Phase C 차단

`η`를 "0에서 시작"한다고만 정했을 뿐 학습 여부·범위·`π_k`의 구현 가능한 초기화가 없다. `c = ∞`는 그대로 구현할 수 없다.

> **권고:** `η = sigmoid(η̂)`, `η̂` 초기 −4(η≈0.018), 층당 스칼라 하나, 학습. `π_k(d) = exp(−d·g/τ_k)`, `g = softplus(ĝ)`, `ĝ` 초기 −5(g≈0.007 ⇒ π≈1), 층당 스칼라 하나, 학습. 온도 `ϑ = 1.0` 고정(v2의 0.25는 초기부터 희소해져 중립극한을 깬다). `W_Q, W_K`는 층 내 population 공유, 초기 `[I 0]`. 초기 `κ`와 support 밀도를 반드시 기록.

### O4. hard-mask(완전 배제) 모드 포함 여부

`η<1`이면 `(1−η)` 바닥이 깔려 sparsemax의 0이 완전 배제로 이어지지 않는다.

> **권고:** 1차 forecasting matrix에는 넣지 않는다. synthetic에서만 `η=1 + sparse` 조건을 하나 두어 "완전 배제가 필요한가"를 확인한다.

### O5. Synthetic 과제의 시간 단위 불일치 — **실행 전 반드시 해소**

원안 Task B는 regime 길이를 **raw step** U[6,16]으로 정의했는데, §4.4의 인코딩은 **patch 하나 = 사건 하나**다. 두 단위가 섞여 있다.

> **권고:** 전부 사건(=patch) 단위로 재정의한다. **T = 42 사건, regime 길이 U[2,5] 사건, key M = 3, 간섭 regime 1–3개, C = 1 채널.** raw 길이는 42×8 = 336이 되어 **ETT와 텐서 형상이 완전히 같아지고**(`[B,336,1]`) data_provider·모델 코드를 그대로 쓸 수 있다.
> - Readout: 사건마다 `Linear(D→1)`. 손실은 전 사건, 보고는 회상 사건 중심.
> - **타이밍:** 시점 n의 선택은 `u_{n+1}`을 바꾸므로 `s_{n+1}`부터 효과가 나타난다. 따라서 주 지표는 **회상 regime의 2번째 사건부터** 집계하고 첫 사건은 별도 열로 보고한다.
> - 표본: train/val/test = 8000/1000/1000 시퀀스, 서로 다른 생성 seed.
> - capacity-matched 대조군 정의: `Linear(8 → D·K)` 로 `D·K`개 독립 스칼라 뉴런(K=1)을 만들고 τ를 순환 배정한다. population 조건과 총 구성원 수를 맞춘다.

### O6. Oracle 강제 방식

> **권고:** 정답 사건 집합 `A_n`에 대해 `p_j = 1/|A_n| (j∈A_n), 0 (j∉A_n)`으로 두고 **동일한 질량보존 변환**을 통과시킨다. 선택자만 교체하고 나머지 경로는 그대로 둔다. **train-time oracle**(학습 내내 강제)과 **test-time oracle**(학습된 모델에 추론 시에만 강제)을 구분해 둘 다 기록한다.

### O7. 사전 판정 수치 확정 — **사용자 승인 필요**

§4.6의 수치는 예시로 적혀 있다.

> **권고(확정안):** 다음 셋을 모두 만족하면 "검색 타당"으로 판정한다. ① 학습 sparse의 정답 사건 질량 ≥ 0.5, ② 회상 MSE ≤ oracle의 1.5배, ③ sparse의 회상 MSE가 full 대비 20% 이상 감소. 한편 **test-time oracle이 full과 5% 이내**면 선택 설계가 아니라 사용 경로(강도·소마·readout)의 문제로 판정하고 Phase C로 되돌아간다.

### O8. 학습 예산·seed·MDE — **ETT 단계 차단**

> **권고:** AdamW lr 1e-3 / wd 1e-2, batch 128, grad clip 1, 최대 50 epoch, early stop 10, ReduceLROnPlateau(0.5, patience 5), 최소 validation MSE checkpoint 복원 후 평가. seed = {7, 13, 21, 42, 123, 256, 512, 1024} (8개).
> **MDE 선언:** v2에서 측정한 ETTh1 H96의 seed 대응 차 SD ≈ 0.0043을 사용하면, n=8 대응 표본·power 0.8·α=0.05에서 검출 가능한 최소 차이는 `(t_{.975,7}+t_{.8,7})·SD/√8 ≈ 3.26×0.0043/2.83 ≈ 0.005`, 즉 **상대 약 1.2%**다. 이보다 작은 차이는 "검출 불가"로 보고하고 유의성을 주장하지 않는다. SD 추정치는 v2(다른 모델)의 값이므로 v3 첫 seed 묶음에서 재추정해 갱신한다.

## 2B. 2026-09-21 Phase B 실행 중 추가 결정 (rev.1 계속)

### D-N. 입력 표준화 `input_norm='frozen'` — 주 설정으로 채택

`Embedding`의 선형사영 출력에 **학습 구간에서 한 번 추정하고 고정한** 유닛별 평균·표준편차를 적용한다. BatchNorm이 아니다: 배치 통계를 쓰지 않으므로 창 분리(G9)와 train/eval 동일성이 유지된다.

- **이유:** `input_scale`은 **이득**이라 모든 입력에서 구동값이 음수인 유닛을 되살릴 수 없다. 회상 과제는 cue가 one-hot이라 유닛 하나의 구동값이 `n_keys`개 이산 준위만 가지며, 세 준위가 모두 음수인 유닛은 **배율을 아무리 키워도 영원히 침묵**한다. 실제로 `input_scale=30`에서도 유닛 19%가 죽어 있었다.
- **측정 (회상 과제 k=3, α=0.7, 학습 구간 1024 시퀀스, mode='full')**

| 설정 | 채택 scale | 발화율 | 죽은 유닛 | 포화 유닛 | 유닛별 발화율 범위 |
|---|---:|---:|---:|---:|---|
| `none` | 17.0 | 0.2151 | **31%** | 6% | 0.000 – 0.926 |
| **`frozen`** | **8.0** | 0.2278 | **0%** | **0%** | **0.178 – 0.248** |

| ETTh1 | 채택 scale | 발화율 | 죽은 유닛 | 유닛별 범위 |
|---|---:|---:|---:|---|
| `none` | 12.0 | 0.2171 | 3% | 0.000 – 0.694 |
| **`frozen`** | **6.0** | 0.1861 | **0%** | **0.049 – 0.256** |

- **부수 효과 — seed 비의존:** `frozen`에서는 seed 7/13/21/42가 **전부 8.0**을 고르고 발화율이 0.227–0.230으로 모인다. `none`에서는 사영 초기화에 따라 동작점이 흔들린다. 보정을 한 번만 하고 모든 seed·조건이 공유한다는 D11 절차가 이로써 실제로 성립한다.
- **게이트 재확인:** `frozen`에서 G9(창 분리) 오차 0.00e+00, G7(중립극한) 비트 단위 동일, train/eval 출력 동일. BatchNorm이었다면 셋 다 깨진다.
- **D11과의 관계:** D11이 금지하는 것은 **구성원별(K축)** gain·threshold 조정이며, 그 이유는 이질성을 지우기 때문이다. 여기서 조정하는 축은 **임베딩 유닛(D축)**이므로 이질성과 무관하다.

### D-O. 난이도 축을 `n_keys ∈ {3, 5, 8}`로 확정 (D-H 개정)

rev.1 D-H는 난이도 축을 "신호 종류 3 → 8 → 16"으로 적었다. **16은 T=42에서 구성 불가능하다.**

| n_keys (`run_range=(2,5)` 고정) | 회상 사건 비율 | 정답 칸 수 | chance mass |
|---:|---:|---:|---:|
| 3 (주 조건) | 75.0% | 3.53 | 0.168 |
| 5 | 58.9% | 3.48 | 0.166 |
| 8 | 33.1% | 3.55 | 0.169 |
| 12 | 1.8% | — | — |
| 16 | **0%** | — | — |

구간 평균이 3.4칸이므로 T=42에는 구간이 약 12개뿐이고, 신호 종류가 그보다 많으면 **재등장 자체가 없다.** `run_range`를 (1,3)으로 줄이면 16도 가능하지만 정답 칸이 3.5개에서 2.0개로 줄어 **chance mass가 0.168 → 0.095로 내려간다.** O7-①의 0.5는 "찍으면 0.15"를 근거로 정한 값이므로, 난이도 수준마다 chance가 달라지면 같은 임계값이 다른 뜻이 된다. 따라서 **`run_range`를 고정하고 축을 3 → 5 → 8로 자른다.** 세 수준의 chance mass가 0.166–0.169로 일치하므로 O7-①을 그대로 적용할 수 있다.

### 정정 — `calibrate.py` 초판의 판정 기준 오류

초판은 "발화율 구간 + **유닛(D축) 사망 0%**"를 통과 조건으로 썼는데, 사전등록 §3 Phase B의 조건은 "발화율 0.1–0.3 + **구성원(K축)** 사망·포화 없음"이다. 사전등록보다 엄격한 조건을 구현이 임의로 추가한 것이므로 사전등록대로 되돌렸다. 유닛별 사망·포화율은 **판정이 아니라 진단**으로 보고한다(D-N의 근거가 된 수치가 바로 그것이다).

## 2C. 2026-09-21 외부 감사(ASSESMENT.md) 수용에 따른 개정

`docs/ASSESMENT.md`의 검증 가능한 지적을 독립 재계산으로 전부 확인했고, 아래를 날짜부로 확정한다.

### D-P. `mass_matched`는 **상한 적용 후** 질량을 맞춘다 (A01, D4·D-H 개정)

```
c_sel      = min(b * rho, b_0)
kappa      = sum(c_sel) / B_n
c_control  = kappa * b                       (kappa<=1, b_j<=b_0 이므로 상한 자동 충족)
```

상한 이전에 맞추면 **항상 `full`이 된다.** `sum_j b_j rho_j = (1-eta)B + eta*B = B`가 항등식이기 때문이다. 재현: 대조군 kappa 1.000000000000000, `|대조군 − full| = 1.11e-16`, 같은 조건에서 선택 모델의 kappa는 0.5698, post-cap 질량 차 6.0062.

`kappa`는 선택자가 만든 상태 의존량이므로 이 대조군의 정확한 이름은 "내용 무관"이 아니라 **"총질량 보존, slot 배분 제거"**다. gradient는 유지한다(처음부터 따로 학습하는 대조군으로도 쓸 수 있어야 하므로). 통과 조건은 게이트 **G16**: 상한 미작동 시 `full`과 비트 단위 일치, 작동 시 `sum(c_control) == sum(c_sel)`(허용오차 1e-12)이고 계수 배열은 다름.

### D-Q. O7-①의 `M_eff`는 **상한 적용 후 계수 비율**이다 (A02)

```
M_eff(n) = sum_{j in A_n} c(n,j) / sum_{j<n} c(n,j) ,    c = min(b*rho, b_0)
```

기존의 `(1−η)m₀ + η`는 **상한 이전의 완벽한 oracle p**에서만 성립하며, 학습된 p에도 상한 이후의 oracle에도 일반적으로 성립하지 않는다. 같은 반례에서 옛 공식 **0.5090**, 실제 **0.1383**이다.

**임계값 0.5는 이미 승인된 기준이므로 내리지 않는다.** 다만 도달 가능성은 학습 결과로 확인할 사항이며, 보고 시 `sum(p)`, 상한 전 `b·rho` 질량, 상한 후 `c` 질량을 각각 독립 계산해 함께 싣는다. 집계 단위는 **query 내부 평균 → sequence 평균 → seed 평균** 순서로 고정한다. history가 없는 `t=0`과 정답 집합이 빈 event는 제외하며 그 개수를 보고한다.

### D-R. 회상 과제 revision **r2** — 소개 후 균등 재질의 (A03, D-O 개정)

r1은 모든 key를 먼저 소개한 뒤 "마지막 등장이 1–3 구간 전"인 key만 후보로 두었다. T=42에는 구간이 약 12개뿐이라 **먼저 소개된 key는 영구히 후보에서 빠진다.** 실측: 실제 다시 질의된 고유 key 수가 n_keys 3/5/8에서 **2.52 / 2.59 / 2.55**로 사실상 동일했다. 즉 **n_keys를 올려도 동시에 보유·회상하는 key 수가 늘지 않았다.**

r2는 1단계에서 모든 key를 한 번씩 소개하고, 2단계에서 `min_gap` 이상 지난 모든 key 중 **균등하게** 재질의한다. `--gap_range`는 `--min_gap`으로 대체한다.

| n_keys (r2) | 회상 사건 | **key coverage** | key당 질의 수 | 평균 정답 lag |
|---:|---:|---:|---:|---:|
| 3 | 75.2% | **99.3%** | 10.63 | 21.18 |
| 5 | 58.5% | **86.4%** | 5.80 | 21.26 |
| 8 | 33.2% | **48.2%** | 3.71 | 22.01 |

**T=42의 구조적 상한을 명시한다.** 구간 수 ≈ 42/3.4 ≈ 12.4이고 소개에 `n_keys`개를 쓰므로 coverage ≈ min(1, (12.4−n_keys)/n_keys). 따라서 **주 난이도 축은 `n_keys ∈ {3, 5}`**(coverage ≥86%)로 하고, **`n_keys=8`은 coverage 48%를 명시한 stress 조건**으로만 보고한다. 이전 r1 결과와 합치지 않는다(r1의 학습 결과는 존재하지 않는다).

정답 집합의 정의를 명시한다: **값이 실제 제시된 첫 구간**이며 직전 재등장 구간이 아니다.

### D-S. chance 기준 두 가지를 분리한다 (A04, D-O 근거 정정)

| 이름 | 정의 | 무엇을 재는가 |
|---|---|---|
| `uniform_slot_chance` | query마다 `\|A_n\| / n`, query 평균 후 sequence 평균 | 과거 칸 하나를 균등하게 고르는 독자 |
| `full_kernel_mass` | `sum_{j in A_n} b(n−j) / sum_{j<n} b(n−j)` | **`η=0`이 이미 정답에 얹는 질량. 선택자가 실제로 이겨야 하는 값** |

기존 보고의 `E[r]/(T/2)`는 틀렸다. query가 시간축에 균등하지 않고 n_keys가 커질수록 뒤로 밀리므로 `E[r/n]`을 `E[r]/(T/2)`로 대체할 수 없다.

| n_keys (r2) | 기존 `E[r]/(T/2)` | **uniform_slot_chance** | **full_kernel_mass** | 0.5 / kernel_mass |
|---:|---:|---:|---:|---:|
| 3 | 0.1662 | **0.1569** | **0.1305** | 3.83× |
| 5 | 0.1649 | **0.1263** | **0.1080** | 4.63× |
| 8 | 0.1640 | **0.1031** | **0.0913** | 5.48× |

**D-O의 근거 문장("세 난이도의 chance가 같으므로 0.5의 의미도 같다")을 철회한다.** chance는 난이도마다 다르다. 0.5는 유지하되, 각 수준에서 `uniform_slot_chance`·`full_kernel_mass` 대비 비율을 함께 보고한다.

### D-T. G11은 **뉴런에 실제로 들어가는 전류**를 감시한다 (A05)

기존 `max_abs_drive`는 `max|raw patch| * scale`이었고, 실제 전류는 `Linear → frozen 표준화 → scale`을 지난 값이다. 회상 과제 보정에서 전자 **8.0**, 실제 **30.504**로 **3.8배 차이**가 났다. 감사가 별도 표본(256 sequence)에서 측정한 30.6887은 **같은 표본의 재현이 아니라 같은 성질의 오류를 독립적으로 지지하는 값**이다. 보정에서 실제 전류를 측정하고, 비유한(NaN/Inf) 발생 시 후보를 탈락시키며, sparse 초기 확인이 구간을 벗어나면 보정 실패로 처리한다.

안정성 주장의 범위도 좁힌다. R3+τ 이동의 sweep는 **유한한 입력·정책·길이의 관측**이며, "모든 η·T에서 유계"가 아니라 "검사한 범위에서 유계"다.

### D-U. `--eta_fixed` / `--no-cap`을 실제로 배선한다 (A06)

두 옵션이 parser와 실험 이름에만 있고 모델에 전달되지 않았다. 이름만 다른 실험이 될 수 있었다. `eta_fixed`는 sigmoid의 큰 logit 근사가 아니라 **정확한 덮어쓰기**이며(η=0, η=1을 정확히 표현), 설정 시 `eta_hat`을 학습에서 제외한다. `--no-cap`은 **별도의 탐색적 안정성 조건**으로 식별한다. 통과 조건은 게이트 **G17**.

### D-V. G4 사유 정정과 G7b 허용오차 명시 (A07)

- **G4:** 기존 사유("torch≥2 CPU 환경 없음")는 **틀렸다.** `snn_jelly`는 torch 2.11.0+cu130이고 CPU forward/backward와 `torch.compile`이 동작한다. 실제 사유는 **고정 커밋 spikeDE 소스가 이 장비에 없다**는 것이다. CUDA 불가는 CPU golden 실행 불가의 근거가 아니다. 등급은 O9대로 `mathematical validation`을 유지한다.
- **G7b:** 등록 문구는 비트 단위였으나 uniform-p 경로는 `sum(b*p)`로 나누고 `full`은 나누지 않으므로 마지막 ulp에서 구조적으로 다르다. 관측 3.33e-16. **허용오차 1e-12를 여기서 명시적으로 등록한다.**
- **G15:** 전압 변화만 보던 것을 **실제 스파이크 변화**로 바꾼다(임계값을 넘는 구동을 구성). 통과: T−1에서 8개 스파이크 변화, 이전 시점 변화 0.

### D-W. 2026-09-21 추적 감사(§9) 수용 — 보정 판정과 진단 정의

추적 감사가 새로 지적한 세 건을 독립 재현한 뒤 수용했다.

| 지적 | 재현한 증상 | 수정 |
|---|---|---|
| **보정이 상한 초과를 거부하지 않음 (P1)** | `max|u|=1001`, 선언 상한 10인 후보를 "closest to target"으로 **선택**했다. `EXCEEDS`를 출력할 뿐 무효화하지 않았다 | `choose()`의 통과 조건에 `within_bound`를 넣는다. 거부 시 사유에 몇 개가 상한/비유한으로 탈락했는지 적는다. `declared_bound`·`within_bound`·`g11_factor`를 JSON에 저장해 **학습 중에도 이 고정 상한을 쓴다**(매번 새 최댓값으로 올리면 상한 검사가 아니다) |
| **`branch_abs_max`가 최댓값이 아님 (P2)** | 배치별 `mean`들의 max를 저장했다. 저장값 `[2.02, 1.18, 0.67, 0.37]` vs 실제 `[12.33, 6.85, 3.69, 2.08]` | `amax(T,B,D)`를 배치 간 max로 모은다. 수정 후 `[19.49, 13.64, 8.35, 4.67]`이며 가장 빠른 가지의 값이 `max_abs_state`와 일치한다 |
| **`cap=False`인데 `cap_rate>0` (P2)** | cap 유무와 무관하게 0.0488로 동일했다. 실제 clipping 빈도가 아니라 `raw > b_0` 잠재 초과율이었다 | **정의를 둘로 나눈다.** `cap_rate` = 반환된 계수가 실제로 잘린 비율(`cap=False`면 0, `mass_matched`는 `κb ≤ b_0`이라 구조적으로 0), `would_cap_rate` = 정책 자체의 잠재 초과율. 수정 후 cap=True 0.0976/0.0976, cap=False 0.0000/0.0976, mass_matched 0.0000/0.0976 |

추가로 보정 artifact의 timestamp를 초 단위로 바꾸고 **배타적 생성(`open(..., 'x')`)**으로 같은 조건 재실행의 덮어쓰기를 막는다. sparse 초기 확인이 실패해 `picked=None`이 되어도 `sparse_at_init` row를 지우지 않고 보존한다.

**기록 정정 두 건.** ① §2C의 날짜를 2026-09-22에서 **2026-09-21**로 고친다(감사와 수정은 모두 2026-09-21 KST에 이루어졌다). ② "실제 30.504가 감사의 30.6887과 일치"는 과한 표현이다. 두 값은 **표본과 조건이 다르며**, 같은 성질의 측정 오류를 독립적으로 지지하는 값이지 동일 표본의 재현 일치가 아니다.

**수용하되 일반화하지 않는 것.** §9.2의 지적대로 r2에서도 `n_keys=8`이 `n_keys=5`보다 더 많은 key의 회상을 평가한다는 증거는 없다(실제 고유 재질의 key 2.98 / 4.32 / 3.86). 정확한 표현은 **"8개 도입, 평균 3.86개 재질의, 낮은 query coverage의 stress 조건"**이며, capacity scaling 일반화는 보류한다. 또 `lag_max`는 "sequence별 평균 lag의 최댓값을 sequence 평균한 값"이므로 표본 전체의 최장 lag로 읽지 않는다. 평가에서는 **recall-only MSE와 재등장 구간 첫 사건 MSE를 분리**해 고정한다(전체 사건 MSE만 보면 key가 많을수록 copy 사건 가중치가 늘어난다).
